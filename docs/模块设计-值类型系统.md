# 模块设计：值类型系统

## 模块位置

`src/value.rs`

## 职责

定义 `Value` 枚举，替代 Python 的动态类型系统，作为所有构造器 parse 的返回类型和 build 的输入类型。

## 详细设计

### Value 枚举

```rust
#[derive(Clone, Debug, PartialEq)]
pub enum Value {
    None,
    Bool(bool),
    Int(i64),
    UInt(u64),
    BigInt(i128),
    Float(f64),
    Bytes(Vec<u8>),
    String(String),
    List(Vec<Value>),
    Container(IndexMap<String, Value>),
}
```

## 设计考量

1. **`IndexMap` vs `BTreeMap`**：使用 `IndexMap` 保持插入顺序（与 Python dict 行为一致），同时支持 O(1) 按键查找
2. **`BigInt(i128)`**：128 位整数足以覆盖绝大多数场景，更大的整数可通过 `Bytes` 表示
3. **`PartialEq`**：仅做浅比较，Container 的比较按 key-value 对逐个比较
4. **不使用 `Any`**：避免运行时类型信息（RTTI）的开销和复杂性

## 与 Python 版本对应

| Python 类型 | Value 变体 |
|------------|-----------|
| `None` | `Value::None` |
| `bool` | `Value::Bool(bool)` |
| `int` | `Value::Int(i64)` / `Value::UInt(u64)` / `Value::BigInt(i128)` |
| `float` | `Value::Float(f64)` |
| `bytes` | `Value::Bytes(Vec<u8>)` |
| `str` | `Value::String(String)` |
| `list` / `ListContainer` | `Value::List(Vec<Value>)` |
| `Container` (dict) | `Value::Container(IndexMap<String, Value>)` |
