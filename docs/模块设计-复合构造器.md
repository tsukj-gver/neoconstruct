# 模块设计：复合构造器（Phase 3）

## 模块位置

| 文件 | 内容 |
|------|------|
| `construct-rs/src/constructs/struct_.rs` | Struct, StructField |
| `construct-rs/src/constructs/sequence.rs` | Sequence, SeqEntry |
| `construct-rs/src/constructs/repetition.rs` | Array, GreedyRange, RepeatUntil, RepeatPredicate |
| `construct-rs/src/constructs/union.rs` | Union, UnionTarget |
| `construct-rs/src/constructs/select.rs` | Select |
| `construct-rs/src/constructs/focused_seq.rs` | FocusedSeq |

## 职责

实现所有复合级构造器——这些构造器内部包含一个或多个子构造器（`Box<dyn Construct>`），负责协调子构造器的 parse/build/sizeof 调用，并管理上下文嵌套和数据聚合。

## 详细设计

### 1. StructField（`constructs/struct_.rs`）

```rust
/// Struct 中的一个字段，包装子构造器并可选地关联名称。
///
/// 对应 Python `Struct(*subcons)` 中的一个位置参数。
/// 命名字段将解析结果插入输出 Container 和上下文；
/// 匿名字段解析结果被丢弃。
pub struct StructField {
    /// 字段名称，`None` 表示匿名字段。
    pub name: Option<String>,
    /// 解析/构建此字段的子构造器。
    pub subcon: Box<dyn Construct>,
}

impl StructField {
    /// 创建命名字段。
    pub fn new(name: impl Into<String>, subcon: Box<dyn Construct>) -> Self;
    /// 创建匿名字段。
    pub fn anonymous(subcon: Box<dyn Construct>) -> Self;
}
```

### 2. Struct（`constructs/struct_.rs`）

```rust
/// 复合构造器：将一系列命名/匿名字段解析为 `Value::Container`。
///
/// 对应 Python `Struct(*subcons)`。
///
/// - parse → `Value::Container(IndexMap<String, Value>)`
/// - build ← `Value::Container`（或 `Value::None` 视为空容器）
/// - sizeof = 所有字段 sizeof 之和
///
/// 上下文嵌套：parse/build 时创建 `ctx.subcontext()` 子上下文。
/// StopField 支持：子构造器返回 `StopField` 时停止处理后续字段。
pub struct Struct {
    fields: Vec<StructField>,
}

impl Struct {
    pub fn new() -> Self;
    pub fn field(self, name: impl Into<String>, subcon: Box<dyn Construct>) -> Self;
    pub fn anonymous(self, subcon: Box<dyn Construct>) -> Self;
    pub fn extend(self, other: Struct) -> Self;
}

impl Default for Struct { fn default() -> Self { Self::new() } }

impl Construct for Struct {
    fn parse(&self, stream: &mut dyn Stream, ctx: &mut Context) -> Result<Value>;
    fn build(&self, data: &Value, stream: &mut dyn Stream, ctx: &mut Context) -> Result<()>;
    fn sizeof(&self, ctx: &Context) -> Result<usize>;
    fn flagbuildnone(&self) -> bool; // 所有字段 flagbuildnone 为 true 时返回 true
}
```

**parse 行为**：
1. 创建子上下文 `child_ctx = ctx.subcontext()`
2. 遍历每个字段：
   - 调用 `field.subcon.parse(stream, &mut child_ctx)`
   - 若返回 `StopField` 错误：`break`（停止处理后续字段）
   - 若为命名字段：将结果插入 `container` 和 `child_ctx`
   - 若为匿名字段：丢弃结果

**build 行为**：
1. 从 `data` 提取 Container（`Value::None` 视为空容器）
2. 创建子上下文，将容器所有键值插入
3. 遍历每个字段：
   - 若 `flagbuildnone()`：值缺失时使用 `Value::None`
   - 否则：必须从容器找到对应名称的值，否则 `FieldMissing` 错误
   - 插入上下文后调用 `field.subcon.build(...)`
   - 若返回 `StopField`：`return Ok(())`

**sizeof 行为**：对所有字段 sizeof 求和（`saturating_add`）。

**flagbuildnone 行为**：所有字段的 `flagbuildnone()` 均为 `true` 时返回 `true`。

### 3. SeqEntry（`constructs/sequence.rs`）

```rust
/// Sequence 中的一个条目。
///
/// 对应 Python `Sequence(*subcons)` 中的一个位置参数。
/// 匿名条目的解析结果仍追加到输出列表（与 Struct 不同）。
pub struct SeqEntry {
    pub name: Option<String>,
    pub subcon: Box<dyn Construct>,
}

impl SeqEntry {
    pub fn new(name: impl Into<String>, subcon: Box<dyn Construct>) -> Self;
    pub fn anonymous(subcon: Box<dyn Construct>) -> Self;
}
```

### 4. Sequence（`constructs/sequence.rs`）

```rust
/// 复合构造器：将一系列条目解析为 `Value::List`。
///
/// 对应 Python `Sequence(*subcons)`。
///
/// - parse → `Value::List(Vec<Value>)`
/// - build ← `Value::List`（或 `Value::None` 展开为等长 None 列表）
/// - sizeof = 所有条目 sizeof 之和
pub struct Sequence {
    entries: Vec<SeqEntry>,
}

impl Sequence {
    pub fn new() -> Self;
    pub fn push(self, subcon: Box<dyn Construct>) -> Self;       // 匿名条目
    pub fn named(self, name: impl Into<String>, subcon: Box<dyn Construct>) -> Self;
    pub fn extend(self, other: Sequence) -> Self;
}

impl Default for Sequence { fn default() -> Self { Self::new() } }

impl Construct for Sequence { ... }
```

**与 Struct 的关键差异**：
- 输出类型：`Value::List` vs `Value::Container`
- 匿名字段：Sequence 仍追加结果到列表；Struct 丢弃结果
- build 时检查：列表长度 ≥ 条目数，否则 `ConstructError::Array`

### 5. Array（`constructs/repetition.rs`）

```rust
/// 固定次数同质数组。
///
/// 对应 Python `Array(count, subcon, discard=False)`。
///
/// - parse → `Value::List`（恰好 count 个元素）
/// - build ← `Value::List`（长度必须 == count，否则 `ConstructError::Array`）
/// - sizeof = count × subcon.sizeof()
pub struct Array {
    pub count: usize,
    pub subcon: Box<dyn Construct>,
    pub discard: bool,
}

impl Array {
    pub fn new(count: usize, subcon: Box<dyn Construct>) -> Self;
    pub fn new_discard(count: usize, subcon: Box<dyn Construct>) -> Self;
}
```

**上下文键**：每次迭代插入 `_index`（`Value::UInt(i)`）。

### 6. GreedyRange（`constructs/repetition.rs`）

```rust
/// 变长同质数组，解析直到流耗尽或子构造器失败。
///
/// 对应 Python `GreedyRange(subcon, discard=False)`。
///
/// - parse → 循环解析，失败时 seek 回退到最后成功位置
/// - build ← 遍历列表构建每个元素
/// - sizeof → `ConstructError::Sizeof`（变长）
pub struct GreedyRange {
    pub subcon: Box<dyn Construct>,
    pub discard: bool,
}

impl GreedyRange {
    pub fn new(subcon: Box<dyn Construct>) -> Self;
    pub fn new_discard(subcon: Box<dyn Construct>) -> Self;
}
```

**parse 终止条件**：
- 子构造器返回 `Ok`：继续
- 子构造器返回 `StopField`：优雅终止（break）
- 子构造器返回其他错误：seek 回退到尝试前位置，终止（break）

### 7. RepeatUntil（`constructs/repetition.rs`）

```rust
/// 谓词函数签名：接收当前元素、已收集列表、上下文，返回是否停止。
///
/// 对应 Python `predicate(obj, list, context) -> bool`。
pub type RepeatPredicate = Box<dyn Fn(&Value, &[Value], &Context) -> bool>;

/// 变长同质数组，重复直到谓词返回 true。
///
/// 对应 Python `RepeatUntil(predicate, subcon, discard=False)`。
///
/// - parse → 循环解析，满足谓词的元素**包含在结果中**
/// - build ← 遍历列表，对每个元素调用谓词，首个满足的元素后停止
/// - sizeof → `ConstructError::Sizeof`（变长）
pub struct RepeatUntil {
    pub predicate: RepeatPredicate,
    pub subcon: Box<dyn Construct>,
    pub discard: bool,
}

impl RepeatUntil {
    pub fn new(predicate: RepeatPredicate, subcon: Box<dyn Construct>) -> Self;
    pub fn new_discard(predicate: RepeatPredicate, subcon: Box<dyn Construct>) -> Self;
}
```

**build 失败条件**：遍历完所有元素后无一个满足谓词 → `ConstructError::Array { expected: 0, actual: 0 }`。

### 8. UnionTarget + Union（`constructs/union.rs`）

```rust
/// 指定 Union parse 后流应前进到哪个子构造器的结束位置。
///
/// 对应 Python `parsefrom` 参数（int=索引, str=名称, None=不前进）。
#[derive(Clone, Debug)]
pub enum UnionTarget {
    Index(usize),
    Name(String),
}

/// 复合构造器：将同一数据视为多个子构造器（类似 C union）。
///
/// 对应 Python `Union(parsefrom, *subcons)`。
///
/// - parse → 所有子构造器从同一位置解析，结果聚合为 Container
/// - build ← 从 Container 中找到第一个匹配名称的子构造器进行构建
/// - sizeof → 所有子构造器 sizeof 的最大值
pub struct Union {
    parsefrom: Option<UnionTarget>,
    subcons: Vec<StructField>,
}

impl Union {
    pub fn new(parsefrom: Option<UnionTarget>, subcons: Vec<StructField>) -> Self;
    pub fn field(self, name: impl Into<String>, subcon: Box<dyn Construct>) -> Self;
    pub fn anonymous(self, subcon: Box<dyn Construct>) -> Self;
}
```

**parse 行为**：
1. 记录起始位置 `fallback`
2. 遍历每个子构造器：
   - 从 `fallback` 位置解析
   - 记录结束位置 `forward_pos`
   - seek 回 `fallback`
3. 若 `parsefrom` 为 `Some(target)`：seek 到目标子构造器的 `forward_pos`

**build 行为**：遍历子构造器，找到第一个名称在 Container 中存在（且非 flagbuildnone 或存在值）的子构造器进行构建。若无匹配 → `ConstructError::Union`。

### 9. Select（`constructs/select.rs`）

```rust
/// 复合构造器：尝试每个子构造器，返回首个成功的。
///
/// 对应 Python `Select(*subcons)`。
///
/// - parse → 依次尝试，失败时 seek 回退，首个成功的结果返回
/// - build → 依次尝试构建到内部缓冲区，首个成功的写入流
/// - sizeof → `ConstructError::Sizeof`（取决于运行时数据）
pub struct Select {
    subcons: Vec<Box<dyn Construct>>,
}

impl Select {
    pub fn new(subcons: Vec<Box<dyn Construct>>) -> Self;
    pub fn push(self, subcon: Box<dyn Construct>) -> Self;
}
```

**parse 失败**：所有子构造器均失败 → `ConstructError::Select`。

### 10. FocusedSeq（`constructs/focused_seq.rs`）

```rust
/// 复合构造器：解析整个序列但仅返回聚焦字段的值。
///
/// 对应 Python `FocusedSeq(parsebuildfrom, *subcons)`。
///
/// - parse → 像 Struct 一样解析所有字段，仅返回 `parsebuildfrom` 字段的值
/// - build ← 聚焦字段接收 build 对象，其余字段接收 `Value::None`
/// - sizeof = 所有子构造器 sizeof 之和
pub struct FocusedSeq {
    parsebuildfrom: String,
    subcons: Vec<StructField>,
}

impl FocusedSeq {
    pub fn new(parsebuildfrom: impl Into<String>, subcons: Vec<StructField>) -> Self;
    pub fn field(self, name: impl Into<String>, subcon: Box<dyn Construct>) -> Self;
    pub fn anonymous(self, subcon: Box<dyn Construct>) -> Self;
}
```

**parse 失败**：聚焦字段未找到 → `ConstructError::FieldMissing`。

## 边界条件清单

### Struct
1. **空 Struct**：parse 返回空 Container，build 接受 `Value::None` 或空 Container
2. **匿名字段**：parse 结果丢弃，build 使用 `Value::None`
3. **flagbuildnone 字段**：build 时值缺失不报错
4. **非 flagbuildnone 字段值缺失**：build → `ConstructError::FieldMissing`
5. **StopField**：子构造器返回 StopField 时优雅停止
6. **非 Container/None 输入 build**：→ `ConstructError::TypeMismatch`

### Sequence
7. **空 Sequence**：parse 返回空 List
8. **build 列表长度 < 条目数**：→ `ConstructError::Array`
9. **build None 输入**：展开为等长 None 列表
10. **StopField**：同 Struct

### Array
11. **count = 0**：parse 返回空 List，build 接受空 List
12. **build 列表长度 ≠ count**：→ `ConstructError::Array`
13. **discard = true**：parse 返回空 List（元素被消费但不收集）

### GreedyRange
14. **空流**：parse 返回空 List
15. **子构造器 EOF**：seek 回退，返回已收集元素
16. **StopField**：优雅终止
17. **sizeof**：→ `ConstructError::Sizeof`

### RepeatUntil
18. **谓词立即满足**：返回含 1 个元素的列表
19. **build 无元素满足谓词**：→ `ConstructError::Array`
20. **流耗尽但谓词未满足**：子构造器 parse 失败传播
21. **sizeof**：→ `ConstructError::Sizeof`

### Union
22. **parsefrom = None**：流不前进（留在原始位置）
23. **parsefrom 索引越界**：→ `ConstructError::Index`
24. **parsefrom 名称不存在**：→ `ConstructError::FieldMissing`
25. **build 无匹配子构造器**：→ `ConstructError::Union`
26. **build 非 Container 输入**：→ `ConstructError::TypeMismatch`

### Select
27. **空 Select**：parse/build → `ConstructError::Select`
28. **所有子构造器失败**：→ `ConstructError::Select`
29. **sizeof**：→ `ConstructError::Sizeof`

### FocusedSeq
30. **聚焦字段不存在**：parse → `ConstructError::FieldMissing`
31. **StopField**：优雅终止
32. **build 非聚焦字段**：使用 `Value::None`

## 设计决策记录

### 决策 1：StructField/SeqEntry 使用 `Option<String>` 区分命名/匿名字段

**Python 方式**：Python 通过 `Renamed` 包装器或 `None` 名称区分，匿名构造器在 `Struct` 中被特殊处理（结果被丢弃）。

**Rust 方式**：`StructField { name: Option<String>, subcon: Box<dyn Construct> }`。`name = None` 表示匿名字段。这比 Python 的动态类型更明确、更安全。

### 决策 2：上下文嵌套通过 `Context::subcontext()` 实现

Struct/Sequence/Union/FocusedSeq 在 parse/build 时创建子上下文，使后续字段可引用先前字段的值。这与 Python 的 `context.__enter__()` / `context.__exit__()` 机制对齐。

### 决策 3：StopField 通过错误类型传播

Python 通过 `StopFieldError` 异常传播停止信号。Rust 使用 `ConstructError::StopField` 变体，复合构造器在遍历中捕获此错误并优雅停止。`GreedyRange` 同样支持 StopField 终止。

### 设计质疑回复：Union sizeof 差异

**质疑来源**：Python `Union._sizeof` 抛出 `SizeofError`，但 Rust 实现返回所有子构造器 sizeof 的最大值。

**回应**：**确认设计为有意偏差（后续处理）**

**说明**：
- Python `Union._sizeof` 抛出 `SizeofError` 是因为 Union 的大小取决于运行时选择构建哪个成员，静态无法确定。
- Rust 实现返回 `max(all_subcons_sizeof)`，这在某些场景下提供了有用的上界估计。
- 此偏差不影响 parse/build 的正确性——sizeof 仅用于预分配，Union 的实际流消费量由 parse 逻辑决定。
- **风险评估**：如果下游代码依赖 sizeof 精确匹配 Union 的流消费量，可能出错。但 Python 版本本身就抛出异常，所以 Rust 的 max 行为是严格更宽松的。
- **后续处理计划**：在 Phase 9（性能优化）中重新评估是否应改为返回 `SizeofError` 以严格对齐 Python。当前不影响任何已通过的测试。

### 设计质疑回复：RepeatUntil build 错误类型

**质疑来源**：Python `RepeatUntil._build` 在无元素满足谓词时抛出 `RepeatError`，Rust 使用 `ConstructError::Array { expected: 0, actual: 0 }`。

**回应**：**确认设计为有意简化（后续处理）**

**说明**：
- Rust 错误体系（Phase 1 设计）中没有独立的 `RepeatError` 变体。
- `ConstructError::Array` 携带 `expected` 和 `actual` 字段，此处 `expected: 0, actual: 0` 语义为"列表长度不满足谓词要求"。
- 此错误足够区分——调用方可通过 `path` 字段定位到 RepeatUntil，通过 `expected == 0 && actual == 0` 识别此场景。
- **后续处理计划**：如需更精确的错误区分，可在未来阶段新增 `ConstructError::Repeat` 变体。当前测试验证行为一致性时未发现问题。

## 与其他模块的交互

### 依赖
- `core::Construct` trait — 所有复合构造器必须实现
- `core::Context` + `Context::subcontext()` — 上下文嵌套
- `core::error::ConstructError` — `StopField`、`Array`、`Select`、`Union`、`FieldMissing`、`Index` 等
- `core::Stream` — `tell()`、`seek()` 用于 Union/Select 的位置管理
- `value::Value` — `Container`、`List` 变体

### 被依赖
- Phase 4 适配器（Enum、Adapter 等）使用复合构造器作为子构造器
- Phase 6 流操作（Prefixed、Pointer 等）使用 Struct/Sequence
- Phase 7 惰性解析（LazyStruct）基于 Struct
- Phase 8 Gallery 使用所有复合构造器
