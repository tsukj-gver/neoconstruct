## 1. 项目定位

将 Python 库 [construct](https://github.com/construct/construct) (v2.10.70) 的核心内核
用 Rust 重写，并通过 PyO3 暴露给 Python。construct 是一个声明式、对称的二进制解析/构建库。

### 1.1 两条用户路径

| 路径 | 用户 | 关注点 |
|------|------|--------|
| **Rust 原生** | 在纯 Rust 项目中直接使用 `construct-rs` crate | 零开销、内存安全 |
| **Python 调用** | 在 Python 项目中 `pip install construct_rust` | 接近/超过 Python 原版性能、声明式 API |

两条路径共享同一套 Rust 内核，但 FFI 边界与产出形式不同。

### 1.2 为何重构（Phase 11 起因）

Phase 1–10 完成了完整内核 + PyO3 封装，但基准测试显示：**construct_rust 在 Python 调用
场景下比 Python 原版慢约 5 倍**（几何平均 0.199x）。根因不是局部优化缺失，而是**架构范式
选择**：per-operation FFI 穿越模型 + Value enum 强制中转 + 混合树，三者叠加构成系统性开销。

详见 `docs/analysis/架构对比分析-pydantic-core.md`（8 个架构缺陷分析）。

### 1.3 重构目标

1. **Python 调用性能**：达到或超过 Python 原版 construct（即从 0.2x 提升到 ≥1.0x）。
2. **保留声明式 API**：用户仍写 `Struct("a"/Byte, "b"/Bytes(this.a))`。
3. **新增 dataclass-first API**：`@dataclass class A(ConstructMixin)`，Container 从用户 API
   彻底消失（见 `docs/analysis/Container必要性与dataclass集成分析.md`）。
4. **Rust 原生路径不退化**：重构后纯 Rust 内核性能不劣于现状。

## 4. 核心设计原则（Phase 11 重构后）

1. **Build-once, run-pure-Rust**：construct 树在构建时一次性编译为纯 Rust 执行树，
   运行时整棵树遍历在 Rust 内完成，最小化 FFI 穿越。
2. **Direct-to-Python（Python 路径）**：parse 直接构建 Python 对象（`PyDict`/dataclass），
   不经 Value enum 中转；build 按需从 Python 对象读取字段。
3. **Value 作为内部中间表示（仅 Rust 路径）**：Value enum 退化为 Rust 纯内核的产出表示，
   不再出现在 Python FFI 的性能关键路径上。
4. **enum_dispatch 零开销分发**：用 `CombinedConstruct` enum 替代 `Box<dyn Construct>`。
5. **惰性 Context 视图**：传给 Python 表达式的 context 是惰性视图，按需转换单个字段，
   不做全量递归转换。
6. **声明式 API 不变**：用户层 API（`Struct`/`"name" / Byte`/`this.field`）保持 Pythonic。

> 上述原则的详细论证见 `refactor/顶层架构设计.md`。

## 5. 与 Python 原版的兼容性目标

| Python construct 概念 | Phase 11 后的地位 |
|----------------------|------------------|
| `Construct` 类（声明式 API） | **完全保留**，是用户主入口 |
| `Container`（产出层） | **退化为内部细节**，dataclass-first API 中对用户不可见 |
| `context`（运行时上下文） | Rust 内核用 `Context`/`IndexMap`，Python 路径用惰性视图 |
| `Stream`（字节流） | Rust 内核保留（construct 领域必需），简化 trait object 使用 |
| 表达式系统 `this`/`obj_` | **完全保留**，常见模式（`this.field`）编译为 Rust 原生求值 |
| `Struct`/`Sequence`/`Array` | 内核保留语义，用 enum_dispatch 分发 |
| `Adapter`/`Enum`/`Switch` | 内核保留语义 |
| `Bitwise`/`Pointer`/`Lazy` | 内核保留语义（construct 领域特有） |

   `refactor/顶层架构设计.md` 的"决策变更记录"节。
