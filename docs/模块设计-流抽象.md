# 模块设计：流抽象

## 模块位置

`src/core/stream.rs`

## 职责

定义流抽象接口 `Stream` trait，提供字节级的读写和定位操作。所有构造器通过此 trait 与底层数据交互。

## 详细设计

### Stream trait

```rust
pub trait Stream {
    /// 读取指定长度的字节到 buf，不足则报错
    fn read_bytes(&mut self, count: usize) -> Result<Vec<u8>>;

    /// 读取指定长度的字节填充到 buf
    fn read_exact(&mut self, buf: &mut [u8]) -> Result<()>;

    /// 写入字节
    fn write_bytes(&mut self, data: &[u8]) -> Result<()>;

    /// 跳转到指定位置
    fn seek(&mut self, pos: u64) -> Result<()>;

    /// 返回当前流位置
    fn tell(&mut self) -> Result<u64>;

    /// 返回流的总大小
    fn size(&mut self) -> Result<u64>;

    /// 检查是否到达流末尾
    fn is_eof(&mut self) -> Result<bool>;
}
```

### ByteStream 实现

基于 `std::io::Cursor<Vec<u8>>` 的内存流实现：

```rust
pub struct ByteStream {
    cursor: Cursor<Vec<u8>>,
}

impl ByteStream {
    /// 从字节切片创建只读流
    pub fn new_read(data: &[u8]) -> Self { ... }

    /// 创建可写流
    pub fn new_write() -> Self { ... }

    /// 从可写流中获取全部已写入数据
    pub fn into_bytes(self) -> Vec<u8> { ... }

    /// 获取当前位置到末尾的剩余数据（不移动游标）
    pub fn remaining_bytes(&mut self) -> Result<Vec<u8>> { ... }
}

impl Stream for ByteStream { ... }
```

### 辅助函数

对应 Python 版本中 `stream_read`, `stream_write` 等辅助函数：

```rust
/// 从流中读取指定长度的字节，不足时抛出 StreamError
pub fn stream_read(stream: &mut dyn Stream, count: usize, path: &str) -> Result<Vec<u8>> {
    stream.read_bytes(count).map_err(|e| {
        ConstructError::Stream {
            path: path.to_string(),
            source: /* io error */,
        }
    })
}

/// 向流中写入字节
pub fn stream_write(stream: &mut dyn Stream, data: &[u8], path: &str) -> Result<()> { ... }

/// Seek 到指定位置
pub fn stream_seek(stream: &mut dyn Stream, offset: i64, path: &str) -> Result<()> { ... }

/// 获取当前流位置
pub fn stream_tell(stream: &mut dyn Stream, path: &str) -> Result<u64> { ... }

/// 获取流大小
pub fn stream_size(stream: &mut dyn Stream, path: &str) -> Result<u64> { ... }

/// 检查是否到达 EOF
pub fn stream_iseof(stream: &mut dyn Stream, path: &str) -> Result<bool> { ... }
```

## 设计考量

1. **自定义 trait 而非直接用 `std::io::Read+Write+Seek`**：
   - 统一错误类型为 `ConstructError`，而非 `std::io::Error`
   - 添加 `size()` 和 `is_eof()` 等便捷方法
   - Phase 6 扩展位级操作时可在 trait 中添加方法

2. **`ByteStream` 使用 `Cursor<Vec<u8>>`**：
   - `Cursor` 提供 Seek 能力
   - `Vec<u8>` 支持动态增长（build 场景）
   - parse 场景使用外部数据切片的拷贝

3. **path 参数在辅助函数中**：
   - Python 版本在每个构造器中直接抛出带 path 的 StreamError
   - Rust 版本通过辅助函数统一添加 path 信息

4. **位级操作预留**：
   - Phase 1 不实现位级读写
   - Phase 6 添加 `BitStream` 包装器实现 `Stream` trait

## 与 Python 版本对应

| `stream_seek(stream, offset)` | `stream_seek(stream, offset, path)` |
