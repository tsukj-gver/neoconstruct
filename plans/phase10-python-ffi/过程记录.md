### ARCH 设计说明

- **PyConstruct API**：共享 helper 函数方案（py_parse/py_build 等 7 个），各 #[pyclass] 构造器委托
- **PyStream**：持有 `Py<PyAny>`，Stream 方法内用 `Python::with_gil` 获取 GIL 调用 Python read/write/seek/tell
- **Context→Container**：递归转换，parent 链写入 `["_"]` 键

### ARCH 设计说明

- **核心决策：纯 Python 方案替代 PyO3**。原版 Container 使用 `self.__dict__ = self` trick 使属性-下标完全等价并支持 method shadowing（`c['update'] = 42` 后 `c.update == 42`）。PyO3 `extends=PyDict` 模式下实例 `__dict__` 与 dict 数据分离，无法原生实现此 trick；需覆盖 `__getattribute__` 并手动实现描述符 fallback，复杂度高且有递归风险。纯 Python 逐行移植原版代码可零差异复刻全部行为
- **Container 类**：继承 dict，`__init__` 中 `self.__dict__ = self`。属性-下标双访问由 trick 自动实现。method shadowing 天然支持（实例字典优先于类型方法）。`__repr__`/`__str__` 受 `@recursion_lock` 保护。`__eq__` 顺序无关、跳过 `_` 前缀键、与普通 dict 可互比。search/search_all 正则搜索（`re.match` 匹配键名）

- **全局打印标志**：3 个模块级变量 + 3 个 setter 函数。只影响 `__str__`，不影响 `__repr__`
- **辅助函数**：`recursion_lock` 装饰器（防 `__repr__`/`__str__` 无限递归，finally 清理确保不残留）、`value_to_string`（bytes 16 字节/str 32 字符截断，EnumInteger/HexDisplayedBytes 类名识别）
