# Phase 13 总纲：FFI 执行层重写

> **阶段目标**：实现 direct-to-Python + 惰性 Context + PyCallback 统一封装，释放编译执行树的性能优势。
>
> **设计文档**：`docs/refactor/模块设计-FFI执行层.md` v2.1
>
> **状态**：DESIGN_REVIEW 通过（v2.1），进入 CODING

## REV 重要问题（本阶段解决）

- #3 PyContextView FFI 开销量化 → 常见表达式零 FFI（编译为闭包），退化路径 owned Context 快照
- #7 Lazy 不兼容 direct-to-PyDict → Phase 13 初始用立即解析，PyLazyProxy 推迟到 Phase 14
- #9 错误路径 PyDict 处理 → 方案 A 丢弃部分 PyDict（与 Python 原版一致）

## 子任务清单

### construct-rs 侧（无 pyo3 依赖）

- [ ] **13.1 OutputSink 协议扩展 + Input trait**
  - OutputSink 新增 `finish_field` / `finish_named_item` / `finish_item` / `into_produced` + `ProducedOutput` enum
  - ValueSink 提供默认实现（零行为变化）
  - 9 个复合 variant exec_parse 从 `into_value+set_field/push_item` 改为 finish 方法（机械化）
  - Input trait 定义（`as_value` / `get_field` / `has_field` / `get_index` / `len` / `sub_input_*`）
  - ValueInput / OwnedValueInput 实现
  - **exec_build 签名变更**：`&Value` → `&dyn Input`（全部 71 variant）
  - 出口：Phase 12 全部测试保持 PASS

- [ ] **13.2 CompiledExtension + External variant**
  - CompiledExtension trait（ext_parse / ext_build / ext_sizeof）
  - CompiledNode 新增 External variant（71 → 72）

  - 出口：编译通过，External variant 在纯 Rust 路径不可达

### construct-py 侧（pyo3 依赖）

- [ ] **13.3 PyDictSink**（依赖 13.1）
  - py_sink.rs（新增）：PyDictSink 实现 OutputSink
  - set_scalar → Value→PyObject 转换 + PyDict::set_item
  - sub_sink_for_field/item → 创建子 PyDictSink（包装子 PyDict/PyList）
  - finish_field/named_item/item → ProducedOutput→PyDict/PyList 写入
  - into_produced → 返回 Object(PyDict/PyList)

- [ ] **13.4 PyInput**（依赖 13.1）
  - py_input.rs（新增）：PyInput 实现 Input
  - 按需读 PyObject 字段（get_field/get_index/has_field）

  - sub_input_field/index → 子 PyInput

- [ ] **13.5 PyContextView**
  - py_context.rs（新增）：PyContextView（#pyclass，unsendable）
  - owned Context 快照（方案 C，零 unsafe）
  - Python Mapping 协议（__getitem__ / __len__ / __contains__ / keys / values）
  - `_` / `_root` / `_params` 惰性访问

- [ ] **13.6 PyCallback + CompiledExpr::External**（依赖 13.2）
  - py_callback.rs（新增）：PyCallback 实现 CompiledExtension

- [ ] **13.7 api.rs 重写 + SchemaCompiler 衔接**（依赖 13.3-13.6）

  - 出口：construct-py 编译通过，Python 端 parse/build 功能完整
