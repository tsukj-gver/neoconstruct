### ARCH 设计说明

**FFI设计.md 核心论点**：
1. FFI 穿越开销（100-300ns）远大于节点计算量（5-20ns），N 字段 = 2N 次穿越会抵消 Rust 优势
2. 编译期构建不可变执行树，运行时只遍历不重建
3. 直接操作 Python 对象，无 Rust 中间类型（中间类型带来三重开销）
4. 静态分派（enum + match）优于动态分派（Box<dyn>）
5. 错误在单次 FFI 内用 PyResult 传播

**Mixin设计.md 核心论点**：
1. `__init_subclass__` 是编译的正确触发点（比元类简单、无冲突）
2. 字段描述符应为 Python 对象（携带参数、支持编译期检查、可组合）
3. 编译产物作为类属性存储，O(1) 查找且不可变
4. 前向引用通过延迟桩（stub）处理
5. `__init_subclass__` 先于 `@dataclass` 执行，编译管线不能依赖 `__dataclass_fields__`
