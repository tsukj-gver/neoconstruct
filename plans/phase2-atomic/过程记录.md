   - f16→f32→f16 roundtrip 在 Rust 中保证幂等（因为 f16 值精确恢复后截断零损失）

2. **Python `_emitparse` / `_emitbuild`**（不影响功能）：
   - Python FormatField 有 `_emitparse`/`_emitbuild` 方法用于加速编译
   - Rust 不需要代码生成优化，不实现这些方法
