# Phase 2: 原子构造器

## 阶段目标

实现所有原子级构造器（atomic constructs），这些是最基础的数据读写单元，直接与字节流交互。本阶段产出的构造器是所有复合构造器的基础构件。

## 前置依赖

- Phase 1 完成（Construct trait, Value, Stream, Context, Error 体系就绪）

## 子任务清单

### 2.1 Bytes 构造器

- [x] 实现 `Bytes` 构造器：读取/写入固定长度字节
  - `parse`: 从流中读取指定长度的字节 → `Value::Bytes`
  - `build`: 将 `Value::Bytes` 写入流
  - `sizeof`: 返回固定长度
- [x] 实现 `GreedyBytes`：读取到流末尾的所有字节
- [x] 实现 `VarInt`（LEB128 变长整数编解码）
- [x] 实现 `ZigZag`（有符号整数 ZigZag 编码 + VarInt）
- [x] 验证：与 Python 版本 `Bytes`, `GreedyBytes`, `VarInt`, `ZigZag` 行为一致

**参考源码**：`construct/construct/core.py` → `Bytes` (line ~924), `GreedyBytes` (line ~993), `VarInt` (line ~1349), `ZigZag` (line ~1422)

### 2.2 FormatField 构造器

- [x] 实现 `FormatField`：基于格式字符的数值字段（对应 Python struct 模块）
   - 支持格式：`bBhHiIqQfd`（大/小端字节序）
   - 引入 `byteorder` crate 或手写实现
   - 提供 `Int8ub`, `Int16ub`, ..., `Float32b`, `Float64b` 等便捷常量
- [x] 验证：多字节序、多格式类型的 parse/build 双向一致性

**参考源码**：`construct/construct/core.py` → `FormatField` (line ~1124), `FormatFieldInt`, `FormatFieldFloat`

### 2.3 BytesInteger / BitsInteger 构造器

- [x] 实现 `BytesInteger`：任意字节数的整数（大/小端字节序）
   - 支持 1-8 字节的标准整数
   - 支持 >8 字节的大整数（可选 `num-bigint`）
- [x] 实现 `BitsInteger`：任意位数（bit）的整数
   - 支持 1-N 位整数提取和构建
- [x] 验证：各种长度的整数 parse/build 正确，大小端一致

**参考源码**：`construct/construct/core.py` → `BytesInteger` (line ~1038), `BitsInteger` (line ~1195)

### 2.4 Flag 构造器

- [x] 实现 `Flag`：单字节布尔值
   - 支持自定义 truthy 值（默认 `1`）
   - parse: 读取一字节，判断是否为 truthy 值
   - build: 根据 bool 值写入 truthy 或 falsy 字节
- [x] 验证：默认行为和自定义 truthy 值均正确

**参考源码**：`construct/construct/core.py` → `Flag` (line ~1524)

### 2.5 Const 构造器

- [x] 实现 `Const`：常量校验
   - parse: 读取数据并验证与预期值匹配
   - build: 写入预期值
   - 支持字节常量和数值常量
- [x] 验证：正确值通过，错误值抛出 `ConstError`

**参考源码**：`construct/construct/core.py` → `Const` (line ~2743)

### 2.6 Pass / Terminator / Tell / Seek / Error 构造器

- [x] `Pass`：无操作构造器（parse 返回 None，build 不写入）
- [x] `Terminated`：验证已到达流末尾
- [x] `Tell`：返回当前流位置（不读写数据）
- [x] `Seek`：跳转到指定流位置
- [x] `Error`：无条件抛出错误（用于 Switch 默认分支等）
- [x] 验证：各构造器行为与 Python 版本一致

**参考源码**：`construct/construct/core.py` → `Pass`, `Terminated`, `Tell`, `Seek`, `Error`

### 2.7 单元测试

- [x] 为每个原子构造器编写 parse/build 对称性测试
- [x] 编写边界条件测试（空字节、最大值、零值）
- [x] 编写错误场景测试（流不足、常量不匹配等）
- [x] 对比 Python 版本输出验证
- [x] 验证：`cargo test` 全部通过

## 阶段出口标准 (Exit Criteria)

1. **编译通过**：`cargo build` 零 error，`cargo clippy` 零 warning
2. **测试通过**：`cargo test` 全部 PASS
3. **功能完整**：
   - 所有 7 类原子构造器可正常使用
   - parse/build 对称性成立（`parse(build(x)) == x`）
   - sizeof 对固定大小构造器返回正确值
4. **API 一致性**：公开 API 与 Python 版本功能对齐
5. **无 panic**：所有非法输入返回 `Err` 而非 panic

## 预估工期

~1.5 周

## 风险与注意事项

- `BitsInteger` 涉及位级操作，需要精确测试大小端和位序
- 大整数（>8 字节）的处理需要决定是否引入 `num-bigint`
- `FormatField` 的格式字符覆盖范围需与 Python struct 模块对齐
- `VarInt` 的 LEB128 编码需同时支持有符号和无符号
