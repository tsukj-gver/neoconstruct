## 行为变更面（发布说明素材）

1. **表达式算术溢出显式化（S1）**：`+`/`-`/`*`/一元负/`//`/`<<`/`>>` 的
   i64 溢出或移位量 ≥64 从静默回绕改为显式 ConstructError（消息含
   "overflow"）。依赖回绕行为的代码（如故意利用掩码语义的 `x << 64`）
   需改用显式位运算常量。
2. **FlagsEnum parse 值形态（S3）**：parse 产出 dict 不再携带
   `_flagsenum` 内部键（全键形态与 build 部分键形态对称）。按 `_flagsenum`
   键存在性做判断的下游代码需移除该依赖（build 侧跳过下划线键规则保留，
   旧形态 dict 仍可 build）。
3. **NamedTuple 编译期校验**：非容器 inner（Struct/Sequence/Array/
   GreedyRange 之外）从 parse 期 NamedTupleError 提前到类创建期
   CompilationError。
4. **Index 严格化**：Index 字段脱离数组迭代上下文从静默 None 改为
   IndexFieldError。
5. **Timestamp 构造期值校验**：unit/epoch 传非 "msdos" 字符串从 parse 期
   TypeError 提前到构造期 TimestampError。
6. **FieldValueMissingError.path**：属性从 None 变为精确字段路径
   （`str(e)` 前缀形态随之统一为 "Error in path …\n…"）。
7. **Probe 输出定位**：嵌入字段的 Probe 打印 `root.<field>` 限定 path。
8. **显式错误透传（S2）**：Adapter 回调中 raise ExplicitError 经
   Select/Peek 透传；嵌入回调中 raise CancelParsing 被顶层捕获返回 None
   （均为此前 docstring 已承诺、本次兑现）。
9. **SizeofError 分类接线**：内核 sizeof 失败变体就位（用户面 API 待后续）。
