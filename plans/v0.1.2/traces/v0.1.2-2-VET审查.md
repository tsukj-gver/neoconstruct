## 2. 重点审查项明细

### B1：Const/Default 隐式 default（_mixin.py L1065-1084）
- **Const value 形态**：ConstDescriptor.value 为常量对象（int/bytes/str），
  `_expr_params={}` 不编译表达式——**表达式形态的 Const 不存在**，无 B1 复发
  通道。不可变常量作 dataclass default 无别名风险；用户传可变对象会被
  dataclasses 自身拒绝（诚实报错）。
- **Default 分支**：`isinstance(value, int)` 判定（bool 子类边缘语义无害）；
  表达式 value → None 是静态求值不可得下的唯一选择（note N-1 记其消费侧残留）。
- **显式优先**：`desc.default is not _MISSING` 分支最先，实测 `D0(d=5).build()
  == b'\x05'` 覆盖。
- **kw_only 传播**：全部隐式 default 分支均 `kw_only=True`；实测隐式字段在前 +
  必填 positional 在后（`M(y=b"ab")`）正常——v0.1.1-2 坑无复发。

### B1f：compute_ro_value Const/Padding 分支（mod.rs L584-592）
- Const → `c.value().clone_ref(py)`：随后 ConstNode.build 收 obj==value 校验
  通过；对齐原版"Const 在 ctx 中可见为常量值"。
- Padding → `py.None()`：与 StopIf/Check 同模式，PaddingNode.build 忽略 obj。
- 仅新增 2 个具名分支，Tell/Computed/Index/Rebuild/Default 既有分支零触碰。
- parse 侧一致性：实测 `A2.parse(b"\x01\x02ab")` → `x==1`（RO 字段 parse 存
  实例值）+ rebuild `b"\x01\x02a"`（尾部 'b' 不消费，docstring 有论证）。

### B3：`_subcon_contains_field_expr`（_mixin.py L944-978）
- 遍历协议（`_EXPR_SLOT_NAMES` 槽位 / `_EXPR_SLOT_LEAF_TYPES` 叶守卫 /
  list·tuple·dict 展开 / 类对象不遍历 / per-field `seen` 防环）与收集器
  `_collect_exprs_from_node` 一致；`seen` 每字段新建（`set()`），模块级单例
  跨字段共享无误判。
- **RU 时序缺口**（note N-2）：helper 在 `_compile_expressions` 之后调用，
  RepeatUntil `_expr_params` 已被 `set_compiled_expr_params` 替换为编译 ops →
  terminator 字段表达式检测不到。实际伤害被"terminator 首引用必须是 Element
  字段"的编译期校验（`_finalize_repeat_until` L886）收窄：WO host（RU 数据）
  本就需用户提供值，隐式 default 无实质收益。docstring 措辞需修正。

### B2：防御排查结论复核 ✅
抽查 3 个消费点源码（compile.rs）：
- Bytes length（L342-368）：expr_programs 缺失 / "length" 键缺失均
  `ConstructError::Compilation`
- Array count（L1792-1812）：同模式
- StopIf cond（L1990-2020）：同模式；另 Computed 防御分支（L437-446）亦报
  Compilation
→ "全部编译期报错、无运行期回退"结论成立；B2 定性修正（显式 StreamError =
数据-schema 不匹配，原版同行为）与 anchor E3/E4 锚点吻合。
