## 3. 红灯清单（疑似库缺陷，2 项；均以 xfail(strict=True) 锁定自然语义期望）

### 红灯 #1：Probe round-trip 断裂（ValueKind 分类缺口）

- 现象：`rfield(Probe())`（其自身 docstring 的推荐用法）parse 正常（值
  None），但**任何 build（含 parse 后立即 build）抛 FieldValueMissingError**
  ——round-trip 不可能成立。`field(Probe())` 同样：必填实例化 + 显式 None
  ≡ 缺值仍报错。
- 根因：`ValueKind::classify`（struct_node.rs L232 `_ => Instance`）——
  ProbeNode 未列入 Control 类。Probe 是 no-value 调试控制节点（parse 返回
  None、build no-op），与 Peek/Seek/Checksum/Tell 同类。
- 期望（[自然]）：Probe 归 Control——实例化可省哑值、build no-op、
  round-trip 字节稳定。
- 位置：`tests/integration/test_display_semantics.py::test_probe_roundtrip_after_parse`

### 红灯 #2：ProcessRotateLeft group=0 build 侧 Rust panic（违反禁 panic 红线）

- 现象：`ProcessRotateLeft(4, 0, ...)` **parse 正确报 RotationError**；但
  build 侧触发 Rust panic（`attempt to calculate the remainder with a
  divisor of zero`，process_rotate_left.rs L121 build 分支
  `(-amount).rem_euclid(group*8)` 在参数校验前执行），以
  `pyo3_runtime.PanicException` 逃逸到 Python 层。
- 违反：AGENTS.md §3 Rust 编码红线"禁止 panic——非法输入必须返回 Err"。
- 期望（[自然]）：与 parse 对称报 RotationError。
- 位置：`tests/integration/test_transform_semantics.py::test_rotate_group_zero_build_raises_rotation_error`

## 4. 实现注记（非红灯的语义观察，测试已按三源锁定）

- 显示/流包装字段（Hex/HexDump/Pointer over Bytes）实例化默认**随 inner
  根节点分类**：over Int → 必填；over Bytes → 可省 None（Bytes 有长度
  参数 → expr_derived 路径）。Sequence 同理随构成（含 GreedyBytes/Default
  可省；全定长必填）。
- Union(None) parse 后流回退：后继字段从回退点重读（GreedyBytes 会读到
  EOF，与视角字节重叠）——按 [自然]+[基线] 锁定。
- Timestamp unit 语义为"每 tick 秒数"（0.001=毫秒 tick），epoch int 为年
  ——按文档示例值 2018-01-01 锚定。
- 环境注记：为本地验证 Timestamp 用例，向 `neoconstruct/.venv` 安装了
  arrow 1.4.0（CI 不装 → 该 7 例在 CI 按设计 skipif 跳过）。
