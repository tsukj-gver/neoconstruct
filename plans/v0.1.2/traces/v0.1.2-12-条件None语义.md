# v0.1.2-12 过程记录：条件字段 build 语义（ValueKind::Conditional）

> 实施依据：ARCH 裁决 R1-R5（条件根 None 透传分支自治 / 普通字段维持
> FieldValueMissing / None ≡ 缺席来源无关 / default=None 只管 __init__ /
> ctx 写 None 与 parse 对称）。

## 1. 内核实现（Rust）

- `struct_node.rs`：
  - `ValueKind` 新增 `Conditional` 变体（不复用 Control——语义表契约不同）。
  - `classify`：增臂 `Node::IfThenElse | Switch | Select => Conditional`
    （根单点判定规则不变，Prefixed 等包装器根仍 Instance）。
  - `init_default`：Conditional → Optional（R4）。
  - build resolve：`Control | Conditional` 合并臂（同形）——getattr，
    AttributeError → None，透传；其余 getattr 错误 Generic 包装
    （错误判据单源收敛）。
- `sequence.rs`：build resolve 增 Conditional 臂——**消费 list 元素**、
  None 透传、元素缺位 ≡ None（缺席来源无关；parse 无条件 append 全部
  字段值，按位置对称取回）。模块 doc 同步。
- `schema.rs`：init_defaults 字段 doc 补 Conditional → Optional。
- 节点层（IfThenElse/Switch/Select/Pass/Const/Default）**零改动** ✓
  （裁决要求）；Union 不纳入 ✓；named_tuple.rs 确认纯委托 inner
  （Struct/Sequence 内字段各自走 classify，自动获得 Conditional 分类），
  无需同步 ✓。
- 新增 Rust 单测 12 个：classify 三根/包装器根仍 Instance/init Optional/
  None 透传 Pass 分支/显式 None/实值分支自然报错（FormatFieldError）/
  显式值透传/回环（struct_node ×8 + sequence ×4）。

  常量表注释说明，其余 8 case 断言恒等。
- 其余 parity 文件：模板增益字段非破坏性（断言只读既有键），全量绿。

## 4. 新用例族（7 族 29 例，ARCH 设计）

`tests/integration/test_conditional_roundtrip_semantics.py`（语义命名）：

| 族 | 数 | 要点 |
|----|----|------|
| A 回环属性 | 6 | parse(x).build()==x：If 真假分支/Switch case+default Pass/Select/IfThenElse 双分支 |
| B 不一致防护 | 4 | 实值分支 + None → 分支自然报错（FormatFieldError/ConstructError，非 FieldValueMissing）；Pass 分支对照成功 |
| C None 三来源等价 | 3 | parse 产出/显式 None/属性不存在（delattr 类级默认使 getattr 真 AttributeError）同字节 |
| D ctx 可见性 | 3 | 条件产出有效值流入后继 Bytes(c)/Switch(k) 分派一致；None 流入消费者显式报错 |
| E 分支内值提供器 | 4 | Const/Default/Padding/双 Padding 分支容忍 None |
| F init 面 | 4 | 实例化可省（Optional）；显式 default= 优先；rfield 从零 build（AttributeError ≡ None）；wfield 假分支回环+真分支丢弃值不可回（WO 固有） |
| G 边界 | 5 | 嵌套条件（内层常量 cond——双层表达式 cond 触发既有同名 'cond' 扁平键编译限制，docstring 注明）/Sequence 条件元素（None 透传+缺位 ≡ None+实值分支）/frozen 回环/Select 全失败 SelectError/Switch 表达式键 |

测试编写期自查修正（用例设计错误非实现缺陷）：A3 Bytes(2) 读前 2 字节
期望值写错；C3/F4 dataclass 类级默认使 hasattr 恒真（改 delattr / getattr
is None）；E1 Const parse 数据缺常量字节；E4 x=0 期望字节笔误；G1 双
表达式 cond 编译限制（改内层常量）；G2 常量真条件与 None 透传设计矛盾
（拆双类）。
