## 2. 问题列表

### 必修（驳回依据）

**P1【设计缺陷·中】Seek/Peek/Checksum 分类缺口——"未来 B5"**
- 位置：§5.1 分类规则（Line 126-130）
- 事实链：①原版三者 flagbuildnone=True（源码实证 core.py:4481/4595/5553，设计 §2 Line 54 全集声明自己也列了）；②设计分类规则未提及 → 无声落 `Instance{expr_derived:false}` → §5.3 init_required 必填哑值；③`field(Peek(Int8ub))`（test_iec104:180,469）、`field(Checksum(...))`（test_modbus_rtu:513）是**已交付用户面真实形态**；④哑值必填正是 B3 同型缺陷在别的构造器上延续。现状 `value_providing` 同样不含三者（框架不引入回归），但"单源分类消灭特判"的完整性声明不成立——分类表内部不自洽（§2 列出全集，§5.1 却无声跳过三者）。
- 建议：ARCH 补显式分类决策。方向参考：Peek/Seek→Control 类（resolve 产 None、节点 build 自理：Peek no-op / Seek 移动流指针）或文档化"有意差异+哑值约定"；Checksum 需结合其 start/end 表达式求值语义单独决策（注意 §5.6 v0.1.3 注入与 Checksum 的 start/end 引用关系）。同时矩阵补 3 者用例锁定。

**P5【测试遗漏·中】B2 数据负例未入矩阵**
- 位置：§8（76 用例全表）
- 事实：总纲 §5 PM 决策记录明确"数据-schema 不匹配的显式 StreamError……数据负例将入矩阵锁定"（B2 定性修正的交付承诺），§8 F 族全部为正例（parse 正常数据/round-trip），无"长度字节与内层需求不匹配 → 显式报错"负例。缺此用例则 B2 修复语义（显式报错而非静默）无回归防线。
- 建议：F 族追加 2-4 例数据负例（如 `Prefixed(Int8ub, Bytes(x+1))` 长度字节声明与 payload 实际不符 → StreamError，期望锚定 .venv-pc 实测）。

### 随修订处理（不单独构成驳回，但 P3/P4 应在重提交版修正）

**P3【文档时效·低】§3 现状表 4 行过时**
- B1（C2().c→None，实测现=5）、B1e（FAIL，实测现 b'\x01ab' OK）、B1f（FAIL"无 Const 分支"，实测现 OK——止血已在 mod.rs:588 补 Const 分支）、B3（"__init__ 即 missing"，实测 W(x=1) 可实例化、错误已后移到 build）均已被 v0.1.2-2 止血修复。仅 B2 行标注了"当前 venv 已由并行止血修复"。会误导 DEV 以为仍是红灯。建议各行补止血状态标注。

**P4【文档精度·低】§2 全集声明非系统枚举**
- 声称"flagbuildnone=True 的类全集＝{Check,Checksum,Computed,Const,Default,Peek,Rebuild,RestreamData,Seek,StopIf}＋{Padding,Tell,Pass}"。源码 grep 实际 15 处（含 anchor 脚本未实测的）：声明**漏 Index、Terminated、Error**。框架/现状均覆盖 Index（ValueKind::Index）/Terminated（Control），Error 构造器未实现。且该全集无 spike 脚本证据（anchor2 仅实测 10 个），与文档开头"所有原版行为均来自 .venv-pc 实测"的声明不符。建议改为源码枚举结果并区分"脚本实测/源码 grep"。

**P2【文档完备·低】compute_ro_value 迁移映射表不完整**
- §5.2 审计表写"全部 10 分支"，实际 11 分支；映射列举缺 `Const→Const`、`Padding→Void`。分类规则（§5.1）已覆盖故无架构影响，但迁移清单是 DEV 实施依据，应补全防漏迁。

**P6【证据链·低】owned-Py 对比代码缺失**
- README/设计 §7 称"spike 仓库保留了两种形态的对比作为 DEV 实施警示"，lib.rs 实际只有就地 Bound 形态+注释，owned 形态 +6.7~9.6% 数字不可复核。建议补 owned 形态函数（或修正 README/设计表述为"数据已测、代码未保留"）。

**P7【验收判据·低】B4-build 点门禁失配**
- §7 主基线 B4-build 3 轮 3389/4357/3922ns（自身波动 ±28%），"各点中位回退 <10%"在该点会随机误报。建议对该点（及其他 >10% 自身波动的点）改用同会话 Controlled A/B（L-09 判据）或注明豁免。

**P8【小点汇总】**
- §5.2 伪码未体现 WO 不写 ctx（正文有述，伪码与文字不一致）；
- anchor_construct.py L1 Tell 用例自身 bug（`Tell()` 单例被调用 → 永久 ERR；anchor2 已修正，链路完整）；
- Sequence Instance 取值（list 位置 vs getattr）未在 §5.2/§11 说明；
- 非 i64 默认值（Default(bytes/str)）延续 ADR-006 i64 VM 限制，矩阵/文档未记录该边界；
- Bytes 显式 None：原版 TypeError、框架合并为 BuildValueMissing，行为差异未在矩阵/差异文档声明；
- depends_on 缺 ADR-005（default 自动 kw_only，§5.3 直接相关）。
