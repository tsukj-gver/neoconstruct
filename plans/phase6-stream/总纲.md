# Phase 6: 流操作与隧道构造器

## 阶段目标

实现流操作和隧道（tunneling）构造器，包括位级操作、流定位、前缀帧、流转换、压缩和加密等高级功能。

## 前置依赖

- Phase 1-5 完成

## 子任务清单

### 6.1 Bitwise / Bytewise

- [ ] 实现 `Bitwise`：位级流包装器
  - 将字节流包装为位级读写流
  - parse: 从字节流中读取指定位数的数据
  - build: 将位数据打包写入字节流
- [ ] 实现 `Bytewise`：在位流上下文中恢复字节级操作
- [ ] 实现 `BitStream` 辅助结构：管理位级读写缓冲
- [ ] 验证：位级操作与 Python 版本一致

**参考源码**：`construct/construct/core.py` → `Bitwise` (line ~1763), `Bytewise` (line ~1859)

### 6.2 Pointer / Peek / RawCopy

- [ ] 实现 `Pointer`：在流的绝对位置读写数据
  - 支持 `offset` 参数（整数或表达式）
  - parse: 记住当前位置 → seek 到 offset → 解析 → seek 回原位置
  - build: 记住当前位置 → seek 到 offset → 构建 → seek 回原位置
- [ ] 实现 `Peek`：解析但不移动流位置
  - parse: 记住位置 → 解析 → seek 回原位置
  - build: 直接构建（无特殊行为）
- [ ] 实现 `RawCopy`：同时返回解析的原始字节和解析结果
  - parse: 记录起止位置，返回 `(raw_bytes, parsed_value)` 的 Container
  - build: 构建并返回原始字节
- [ ] 验证：流定位操作正确，不影响后续解析

**参考源码**：`construct/construct/core.py` → `Pointer` (line ~3903), `Peek` (line ~4134), `RawCopy` (line ~4190)

### 6.3 Prefixed

- [ ] 实现 `Prefixed`：前缀长度帧
  - parse: 读取长度字段 → 仅读取指定长度的数据 → 传给子构造器
  - build: 先构建子构造器 → 写入长度 → 写入数据
  - 支持自定义长度字段构造器
- [ ] 验证：前缀帧正确，长度字段与数据匹配

**参考源码**：`construct/construct/core.py` → `Prefixed` (line ~3143)

### 6.4 Transformed / Restreamed

- [ ] 实现 `Transformed`：对整个数据块进行转换后传给子构造器
  - parse: 读取全部数据 → decode 转换 → 传给子构造器
  - build: 子构造器构建 → encode 转换 → 写入
- [ ] 实现 `Restreamed`：逐块流式转换
  - 包装流，在每次读写时进行转换
  - 支持自定义 read/write/size 函数
- [ ] 实现 `RestreamData`：使用另一个字段的数据作为子流
- [ ] 验证：流转换正确，转换后子构造器可正确解析

**参考源码**：`construct/construct/core.py` → `Transformed` (line ~4284), `Restreamed` (line ~4382), `RestreamData` (line ~4533)

## 阶段出口标准 (Exit Criteria)

1. **编译通过**：`cargo build` / `cargo clippy` 无问题
2. **测试通过**：`cargo test` 全部 PASS（含可选依赖测试）
3. **功能完整**：
   - Bitwise/Bytewise 位级操作正确
   - Pointer/Peek/RawCopy 流定位正确
   - Prefixed 前缀帧正确
   - Transformed/Restreamed 流转换正确
   - Compressed 压缩/解压缩正确（可选）
   - EncryptedSym 加密/解密正确（可选）
4. **无数据损坏**：所有流操作前后数据一致性

## 预估工期

~1.5 周

## 风险与注意事项

- `Bitwise` 的位级流实现是本阶段最复杂的部分，需要仔细处理字节对齐
- `Restreamed` 的逐块转换需要高效的缓冲区管理
- 压缩和加密功能依赖外部 crate，需要做好 feature gate
- `Pointer` 的 seek 操作在非可寻址流上会失败，需要正确处理
