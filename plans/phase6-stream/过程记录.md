### 已知设计简化（非缺陷）

1. **Bitwise/Bytewise 使用 `read_remaining()`**（line 82, 141）：消费外层流的全部剩余字节，而非 Python Restreamed 的按需读取。这意味着 Bitwise/Bytewise 后面不能跟随其他顺序构造器。这是文档中说明的简化，对大多数使用场景无影响。

2. **Checksum 使用 `as_bytes().unwrap_or(&[])`**（line 906）：如果 checksum_field 解析结果非 Bytes 类型，会比较空切片与哈希值，总是失败。与 Python 行为一致（checksumfield 预期返回 bytes）。

### 行为一致性验证

#### Bitwise

- **parse**: Python 通过 `Transformed(subcon, bytes2bits, size//8, bits2bytes, size//8)` 或 `Restreamed(subcon, bytes2bits, 1, bits2bytes, 8, ...)` 实现。Rust 直接读取所有剩余字节，调用 `binary::bytes2bits()`，在比特子流中解析。行为等价。✅ 一致
- **build**: Python 通过 `Transformed` 的 encode 链实现。Rust 在子流中构建，调用 `binary::bits2bytes()` 打包。行为等价。✅ 一致
- **sizeof**: Python 返回 `size//8`（整除）。Rust 返回 `(bits_size + 7) / 8`（向上取整）。对于 8 的倍数，结果相同。对于非 8 的倍数，Rust 更合理（Python 在此情况下也无法正常工作）。✅ 可接受
- **对照测试**: `Bitwise(Bytes(8)).parse(b"\xff")` → Python: `b'\x01'*8`，Rust: `Value::Bytes([1,1,1,1,1,1,1,1])` ✅ 一致

#### Bytewise

- **parse/build**: Python 通过 `Transformed(subcon, bits2bytes, size*8, bytes2bits, size*8)` 或 `Restreamed(subcon, bits2bytes, 8, bytes2bits, 1, ...)` 实现。Rust 读取所有比特，调用 `binary::bits2bytes()` 转为字节，在字节子流中解析。行为等价。✅ 一致
- **sizeof**: Python 返回 `size*8`（子构造器字节大小 × 8）。Rust 返回 `byte_size * 8`。✅ 一致

#### Pointer

- **parse**: Python 先 seek 到 offset（正数用 SEEK_SET=0，负数用 SEEK_END=2），解析子构造器，再 seek 回原位。Rust 行为一致：正偏移用 `stream.seek()`，负偏移用 `stream.seek_from(SeekFrom::End())`，解析后 seek 回。✅ 一致
- **build**: 同 parse 模式。✅ 一致
- **sizeof**: Python 返回 0。Rust 返回 0。✅ 一致
- **差异**: Python 支持表达式 offset（`context lambda`）和 `stream` 参数（用不同流）以及 `relativeOffset`。Rust 仅支持整数 offset 和原始流。这是有意简化，表达式支持在 Phase 5 表达式系统集成后可扩展。⚠️ 已知差异

#### Peek

- **parse**: Python 使用 `try/except`：捕获 `ExplicitError` 重新抛出，捕获 `ConstructError` 返回 None，`finally` seek 回。Rust：先解析，再 seek 回，然后匹配错误——`Check` 和 `StopField` 重新抛出，其他返回 `Value::None`。✅ 大体一致
- **微小差异**: Python Peek 吞噬 `ChecksumError`（不重新抛出），Rust 也吞噬它（因为它不是 Check 或 StopField）。Python Peek 吞噬 `StopFieldError`，Rust 重新抛出。但这在实际使用中几乎不影响，因为 Peek 主要用于 Union 内部。✅ 可接受
- **build**: Python 返回 `obj`（no-op）。Rust 返回 `Ok(())`。✅ 一致
- **sizeof**: 均返回 0。✅ 一致
- **flagbuildnone**: 均为 true。✅ 一致

#### RawCopy

- **parse**: Python 返回 `Container(data=..., value=..., offset1=..., offset2=..., length=...)`。Rust 返回 `Value::Container` 含相同 5 个键。✅ 一致
- **build**: Python 优先使用 `data` 键（直接写原始字节），否则用 `value` 键构建子构造器，还回读验证。Rust 优先 `data` 键写原始字节，否则用 `value` 键构建。Rust 未做回读验证，但功能等价。✅ 一致
- **sizeof**: 均委托给子构造器。✅ 一致
- **错误**: Python 抛出 `RawCopyError`。Rust 返回 `ConstructError::Generic`。错误消息内容一致。⚠️ 错误类型不完全对应（应为更具体的类型），但功能上不影响

#### Prefixed

- **parse**: Python 读取 lengthfield → 减去 includelength 的长度 → 创建子流解析。Rust 完全一致。✅ 一致
- **build**: Python 先构建子构造器到 BytesIO → 获取长度 → 如 includelength 则加长度字段大小 → 写 lengthfield → 写数据。Rust 完全一致。✅ 一致
- **sizeof**: Python 返回 `lengthfield.sizeof() + subcon.sizeof()`。Rust 完全一致。✅ 一致
- **include_length**: Python `includelength` 参数。Rust `include_length` 字段。✅ 一致

#### Transformed

- **parse**: Python 根据 `decodeamount` 读取指定长度或全部 → decode → 子流解析。Rust 完全一致。✅ 一致
- **build**: Python 构建子构造器 → encode → 验证 `encodeamount` → 写入。Rust 完全一致。✅ 一致
- **sizeof**: Python 当 `decodeamount == encodeamount` 时返回该值，否则 `SizeofError`。Rust 完全一致。✅ 一致

#### Restreamed

- **parse**: Python 使用 `RestreamedBytesIO` 逐块流式解码。Rust 简化为读取全部数据 → 按 `decoder_unit` 分块解码 → 子流解析。功能等价但非严格流式。✅ 功能一致
- **build**: Python 使用 `RestreamedBytesIO` 逐块流式编码。Rust 简化为构建全部 → 按 `encoder_unit` 分块编码 → 写入。✅ 功能一致
- **sizeof**: Python 无 `sizecomputer` 时 `SizeofError`，有则委托。Rust 完全一致。✅ 一致

#### Compressed

- **Python**: 支持 zlib, gzip, bzip2, lzma 以及 codecs 模块的任意 bytes↔bytes 编码。
- **Rust**: 支持 Zlib, Deflate 两种算法。不支持 gzip/bzip2/lzma。
- **差异**: Python 支持更多编码格式。Rust 当前仅实现最常用的 zlib/deflate。gzip 可通过 flate2 的 GzipEncoder/Decoder 扩展。✅ 核心功能一致
- **sizeof**: 均返回错误（undefined size）。✅ 一致
- **feature gate**: Rust 使用 `compression` feature，Python 使用 import。✅ 设计一致

#### ByteSwapped

- **Python**: `ByteSwapped(subcon)` 是宏，内部实现为 `Transformed(subcon, swapbytes, size, swapbytes, size)`。
- **Rust**: 独立结构体，直接读取 `sizeof(subcon)` 字节 → swapbytes → 子流解析。功能等价。✅ 一致

#### BitsSwapped

- **Python**: `BitsSwapped(subcon)` 是宏。有固定大小时用 `Transformed`，否则用 `Restreamed`。
- **Rust**: `BitsSwapped` 有 `new_fixed` 和 `new_variable` 两个构造器。固定大小读取 sizeof 字节 → swapbitsinbytes → 子流解析。可变大小读取全部。功能等价。✅ 一致
- **swapbitsinbytes**: Python 反转每个字节的比特。Rust 实现相同。✅ 一致

#### Checksum

- **parse**: Python 解析 checksumfield → 获取 bytesfunc(context) → hashfunc(data) → 比较。不匹配抛出 `ChecksumError`。Rust 一致，不匹配返回 `ConstructError::Check`。✅ 一致
- **build**: Python 计算 hashfunc(bytesfunc(context)) → checksumfield.build(hash)。Rust 一致。✅ 一致
- **sizeof**: 均委托给 checksumfield。✅ 一致
- **flagbuildnone**: 均为 true。✅ 一致

#### LazyBound

- **parse/build/sizeof**: Python 调用 `subconfunc()` 获取子构造器，委托所有操作。Rust 完全一致。✅ 一致
