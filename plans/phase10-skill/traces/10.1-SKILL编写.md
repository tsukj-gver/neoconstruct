### field 函数 + 表达式系统

- `field(subcon, default=None, context=None)` —— RW 字段
- `rfield(subcon, context=None)` —— RO 字段（自动算）
- `wfield(subcon, default=None, context=None)` —— WO 字段（padding/reserved）
- 表达式运算符：`+ - * // % & | ^ << >> - ~ == != < <= > >=`（不支持 `/` `and`/`or`）

## 6. 自评：SKILL 是否自包含充分？

### 强项

1. **100% API 覆盖**：用户面公开构造器全部列出，每个有一行说明
2. **易错点前置**：Phase 9 实战发现的所有 API gap 都在 §5 显式列出，给替代方案
3. **完整可运行示例**：4 个真实工业协议，覆盖任务要求的三大能力（条件分支+bitfield+CRC）
4. **教学法组织**：先核心理念 → 最小示例 → API 速查 → 模式 Cookbook → 易错点 →
   完整示例 → 调试 → 速查表 → 实现步骤。从零到精通的完整路径
5. **代码即文档**：所有模式都有完整代码（含 import + @dataclass + parse/build），
   不是 API 参考的简单罗列

### 可能的不足

1. **构造器清单是表格而非完整 docstring**：用户面构造器仅一行说明，详细参数（如
   `NullTerminated` 的 include/consume/require）未深入展开。如果验证协议用到这些
   参数，agent 可能需要试错。**缓解**：§4 Cookbook 给了最常用模式；详细参数文档在
   _descriptors.py docstring（但本任务要求 SKILL 自包含）
2. **用户自定义 Adapter 未深入**：§3.3 仅列出 `Adapter` 基类一行说明，未给完整示例。
   如果验证协议需要自定义 _decode/_encode，agent 可能不知道如何下手。**缓解**：本任务
   要求的三大能力（条件分支+bitfield+CRC）不需要自定义 Adapter
3. **延迟编译机制未提**：嵌套子 Struct 的前向引用（子类在父类之后定义）会触发延迟编译。
   SKILL 没显式说明，但示例都是"先子类后父类"的顺序，不会触发。**缓解**：§5.9 提到
   前向引用有延迟编译机制
4. **性能数据未给**：SKILL 聚焦用法，未给具体加速比数据。**缓解**：§1 提到"≥4x vs
   Python construct"，agent 知道性能目标即可
5. **RepeatUntil + Index + Element 未给完整示例**：§3.3 列出但 §4 Cookbook 没展开
   （这三个构造器较高级，本任务三大能力不需要）。**缓解**：API 速查表有说明

### 综合判断

**SKILL 足以让不了解 construct-rs 的 agent 单轮实现复杂协议**。

理由：
- 任务要求的三大能力（条件分支 + bitfield + CRC）在 §4 + §5 + §6 都有完整覆盖
- 4 个真实协议示例涵盖了所有典型组合
- 10 个易错点（含任务要求的 6 项）显式列出替代方案
- API 速查表（§8）让 agent 快速找到对应模式

可能的不足主要在边缘构造器（NullTerminated 细节参数、自定义 Adapter、RepeatUntil），
这些不在任务要求的三大能力范围内。

### 11.4 关键修正：§4.5.5 代码块反惯例

初版 §4.5.5 示例直接 `d_a = Prefixed(...); d_a.build(payload)` —— 实跑报
`AttributeError: 'PrefixedDescriptor' object has no attribute 'build'`。

**根因**：`Prefixed` 是**描述符**（`PrefixedDescriptor`），必须用 `@dataclass` 包装
后经 `__init_subclass__` 编译才能 parse/build。这与 SKILL 全书惯例一致（§2/§4.1+
所有 Cookbook 都用 @dataclass），初版代码块是反惯例笔误。

**修正**（`10.1e` 脚本）：改为 `@dataclass class ChunkA(StructMixin): data = field(Prefixed(...))`
包装，字节值不变（已由 `10.1d` 验证脚本确认：built_a=0003aabbcc / built_b=0005aabbcc）。

**经验**：所有新增代码示例必须**实跑验证**，不能仅靠语义推算写 assert。
