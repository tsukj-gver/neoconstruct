# Phase 7: 惰性解析

## 阶段目标

实现惰性解析构造器，允许按需解析大型数据结构，仅在字段被访问时才进行实际解析。

## 前置依赖

- Phase 1-6 完成

## 子任务清单

### 7.1 Lazy 基础

- [x] 实现 `Lazy`：包装子构造器，延迟解析
  - parse: 记录流偏移和子构造器，返回 `LazyValue`
  - `LazyValue`：首次访问时解析，缓存结果
  - build: 直接构建（不延迟）
- [x] `LazyValue` 实现 `Deref` 或类似机制，透明访问
- [x] 验证：延迟解析正确，多次访问返回缓存值

**参考源码**：`construct/construct/core.py` → `Lazy` (line ~4713)

### 7.2 LazyStruct

- [x] 实现 `LazyStruct`：Struct 的惰性版本
  - parse: 为每个字段创建 `LazyValue`，返回 `LazyContainer`
  - `LazyContainer`：字段按需解析
  - build: 与普通 Struct 相同
- [x] 验证：仅访问部分字段时只解析必要的部分

**参考源码**：`construct/construct/core.py` → `LazyStruct` (line ~4779)

### 7.3 LazyArray / LazyRange

- [x] 实现 `LazyArray`：数组的惰性版本
  - parse: 记录每个元素的偏移，返回 `LazyListContainer`
  - 按需解析单个元素
- [x] 验证：惰性数组按需解析正确

**参考源码**：`construct/construct/core.py` → `LazyRange`

### 7.4 LazyBound

- [x] 实现 `LazyBound`：通过闭包延迟绑定子构造器
  - 用于处理递归数据结构（如链表、树）
  - parse/build 时通过闭包获取实际构造器
- [x] 验证：递归结构正确解析

**参考源码**：`construct/construct/core.py` → `LazyBound` (line ~4901)

### 7.5 Rebuffered

- [x] 实现 `Rebuffered`：缓冲非可寻址流
  - 将非 seekable 流包装为 seekable
  - 内部使用缓冲区缓存已读数据
- [x] 验证：在非 seekable 流上正确工作

**参考源码**：`construct/construct/core.py` → `Rebuffered` (line ~4959)

### 7.6 单元测试

- [x] 测试 Lazy 延迟解析和缓存机制
- [x] 测试 LazyStruct 字段按需解析
- [x] 测试 LazyArray 元素按需解析

## 阶段出口标准 (Exit Criteria)

1. **编译通过**：`cargo build` / `cargo clippy` 无问题
2. **测试通过**：`cargo test` 全部 PASS
3. **功能完整（方案 A：即时解析）**：
   - `Lazy` 记录偏移 + 即时解析，round-trip 等价 ✅
   - `LazyStruct` 委托 Struct 即时解析，round-trip 等价 ✅
   - `LazyArray` 委托 Array 即时解析，round-trip 等价 ✅
   - `LazyBound` 闭包延迟绑定子构造器正确 ✅
   - `Rebuffered` 非可寻址流缓冲正确 ✅
   - > **设计决策（ARCH 裁定）**：Phase 7 采用方案 A（即时解析策略），真正的按需惰性解析推迟至 Phase 9。
   - > 理由：`Value` 枚举是具体类型（非动态），无法表示"延迟物化"状态。引入 `Value::Lazy` 变体将影响 Phase 1-6 全部已验收代码（50+ match 分支、1090 测试回归风险）。详见 `docs/模块设计-惰性解析.md` §1 和 §6。
4. **性能验证**：~~惰性解析确实减少了解析开销（仅解析访问的字段）~~
   - > **推迟至 Phase 9**：方案 A（即时解析）的 round-trip 等价性保证了正确性。真正的惰性性能优化在 Phase 9 实现 `Value::Lazy` 后验证。

## 预估工期

~1 周

## 风险与注意事项

- `LazyValue` 需要持有流的引用或副本，需考虑生命周期和所有权
- `LazyStruct` 和 `LazyArray` 需要精确的流偏移计算
- `LazyBound` 的递归结构可能导致栈溢出，需要考虑深度限制
- Rust 的 `OnceCell` / `RefCell` 可能用于实现延迟初始化
