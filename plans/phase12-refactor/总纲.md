## 核心设计决策（ARCH v2）

| 决策 | 选择 | 理由 |
|------|------|------|
| CompiledNode vs CombinedConstruct | 选项 B：全新 enum，与 CombinedConstruct 平行 | 职责分离（声明树 vs 执行树），叶子 variant 直接内嵌 CombinedConstruct 具体类型 |
| SchemaCompiler 内省 | 直接 match CombinedConstruct | PyO3 wrapper 持有 Rust 内核构造器（inner 字段），直接 enum match |
| Sink 机制 | trait object（`&mut dyn OutputSink`） | 非 enum 非泛型，一次虚分发 per 字段写入 |
| PyCallback | 不定义（推迟到 Phase 13） | construct-rs 不依赖 pyo3 |

## 出口标准

1. **编译**：`cargo build` 零错误零警告
2. **Clippy**：`cargo clippy -- -D warnings` 退出码 0
3. **格式**：`cargo fmt --check` 退出码 0
4. **测试**：`cargo test` 全 PASS（Phase 1-11 测试不退化 + 新增编译执行树等价性测试）
5. **新路径可用**：`CompiledSchema::parse_bytes(data) -> Result<Value>` 可用（纯 Rust 路径）
6. **等价性**：编译执行树 parse/build 结果与旧路径（直接 CombinedConstruct::parse）逐字段相等
7. **缓存**：同一 schema 二次编译返回缓存的 CompiledSchema
8. **性能**：编译执行树 parse 性能不劣于旧路径（enum_dispatch 零虚分发 + 编译期固化参数）
