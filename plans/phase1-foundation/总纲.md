# Phase 1: 垂直切片验证

## 阶段目标

实现最小端到端路径，验证架构可行性与性能 ≥4x。`examples/example.py` 的 ModbusRTUMessage 必须可 parse/build，性能超过 Python construct 2.10.70 至少 4 倍。

## 前置依赖

- Phase 0 架构设计验收通过 ✅

`docs/架构设计.md` 是 Phase 1 编码的唯一设计依据。该文档提供了精确到可编码的 Rust trait 签名、节点结构体定义、FFI 入口签名、Python 接口。Phase 1 子任务跳过 DESIGNING/DESIGN_REVIEW，直接进入 CODING → CODE_REVIEW。

## REV 遗留的非阻塞约束（DEV 编码时必须遵守）

1. **Bytes build 仅接受 bytes 输入**（int/bytearray 转换推迟）
2. **FormatField build 用 `try_into` 显式校验值范围**，禁止 `as u8` 截断
3. **Phase 1 不支持字段继承**（只查当前类 `__dict__`，不遍历 MRO）
