### 设计决策说明
1. **Python 包位置**：当前工作区根目录 `construct/` 是 Python 原版 construct 2.10.70
   仓库（只读参考）。为避免冲突，将我们的 Python 包放在 `construct-rs/python/construct/`，
   并在 pyproject.toml 设置 `python-source = "python"` 告知 maturin。已验证 maturin 正确
   将 Rust 扩展编译安装为 `construct._construct_rust`。
2. **pyo3 兼容性**：Python 3.14 需设置环境变量 `PYO3_USE_ABI3_FORWARD_COMPATIBILITY=1`
   方可使 pyo3 0.22 通过版本检查。后续子任务运行 cargo/maturin 命令均需携带此环境变量。
3. **features 配置**：pyproject.toml 的 `[tool.maturin].features = ["pyo3/extension-module"]`
   确保 maturin 构建时启用扩展模块特性（避免链接 Python 解释器）。
