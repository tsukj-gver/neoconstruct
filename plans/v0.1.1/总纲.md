## 1. 用户反馈的 BUG

### BUG-1：Switch 在 Prefixed 包装下无法透传根节点字段

```python
@dataclass
class P(StructMixin):
    typ: int = field(Int8ub)
    br: Any = field(Prefixed(Int8ub, Switch(typ, {...})))
```

Switch 的 keyfunc 引用 `typ`（根 Struct 字段），经 Prefixed 包装后无法解析到根上下文字段。

- 类型：表达式上下文传播（疑似嵌套构造器内 ctx 作用域问题）
- 关联历史：Phase 9 API gap 4.3（Computed 只能引用兄弟字段）可能是同一族问题——嵌套/跨层字段引用的作用域边界

### BUG-2：Const / Default 作为 field 时未自动提供 dataclass default

```python
@dataclass
class P(StructMixin):
    v: int = field(Const(5))   # 实例化 P() 报 TypeError: missing arguments
```

用户预期：Const/Default 语义上值固定/有默认，dataclass 实例化不应强制提供该参数。

- 类型：Python 用户面（`_descriptors.py` / field 包装层）与 dataclass 语义的集成问题
