## 3. P8 修复（_system_helpers.py）

`get_rs_python()` / `get_py_python()` 改为与 conftest.py 的 `rs_python` / `py_python`
fixture 完全一致的解析顺序。diff 摘要：

```python
# 修复前（get_rs_python；get_py_python 同构，仅无冗余 env 行）
def get_rs_python() -> str:
    env = sys.executable          # 冗余变量
    if _RS_PYTHON.exists():       # 硬编码原开发机路径优先，不读环境变量
        return str(_RS_PYTHON)
    return env

# 修复后（两个函数同构；新增 import os）
def get_rs_python() -> str:
    env = os.environ.get("CRS_PYTHON")      # 1. 环境变量（路径存在时优先）
    if env and Path(env).exists():
        return env
    if _RS_PYTHON.exists():                 # 2. 硬编码 fallback（原开发机）
        return str(_RS_PYTHON)
    return sys.executable                   # 3. 最后手段
```

硬编码路径常量（L26-28）保留为 fallback（与 conftest.py 的 _DEFAULT_* 同源同值），
未删除——删除会破坏原开发机（<dev-user>）的无环境变量默认行为。
