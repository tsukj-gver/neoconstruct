# Phase 4: 适配器与控制流构造器

## 阶段目标

实现适配器层（Adapter/SymmetricAdapter/Validator/ExprAdapter 等）和条件控制流构造器（If/IfThenElse/Switch/Check 等），为数据转换和条件逻辑提供基础设施。

## 前置依赖

- Phase 1 完成
- Phase 2 完成
- Phase 3 完成（复合构造器可用）

## 子任务清单

### 4.1 Adapter 基础架构

- [ ] 实现 `Subconstruct` trait 或机制（包装内部构造器的基类）
- [ ] 实现 `Adapter` trait / struct：
  - `decode(raw) -> Value` — 将原始解析值转换
  - `encode(value) -> Value` — 将用户值转换为构建值
  - parse: 子构造器解析 → decode
  - build: encode → 子构造器构建
- [ ] 实现 `SymmetricAdapter`（decode == encode）
- [ ] 实现 `ExprAdapter`（使用表达式进行 decode/encode）
- [ ] 验证：适配器正确包装子构造器

**参考源码**：`construct/construct/core.py` → `Subconstruct` (line ~787), `Adapter` (line ~813), `SymmetricAdapter` (line ~837), `ExprAdapter` (line ~851)

### 4.2 Validator / ExprValidator

- [ ] 实现 `Validator`：校验解析/构建值
  - `validate(value) -> bool`
  - parse/build 时调用 validate，失败抛出 `ValidationError`
- [ ] 实现 `ExprValidator`：使用表达式校验
- [ ] 验证：合法值通过，非法值正确报错

**参考源码**：`construct/construct/core.py` → `Validator` (line ~849), `ExprValidator` (line ~875)

### 4.3 Enum / FlagsEnum / Mapping

- [ ] 实现 `Enum`：枚举映射（整数 ↔ 字符串）
  - parse: 读取原始值，查找映射表，返回字符串
  - build: 从字符串查找对应原始值
  - 支持默认映射
- [ ] 实现 `FlagsEnum`：位标志枚举
  - parse: 将整数的各 bit 位映射为 flag 集合
  - build: 从 flag 集合构建整数
- [ ] 实现 `Mapping`：通用双向映射
- [ ] 验证：正向/反向映射正确，缺失键行为正确

**参考源码**：`construct/construct/core.py` → `Enum` (line ~3227), `FlagsEnum` (line ~3317), `Mapping` (line ~3425)

### 4.4 Hex / HexDump

- [ ] 实现 `Hex`：将整数/字节转换为十六进制显示字符串
- [ ] 实现 `HexDump`：将字节转换为 hexdump 格式显示
- [ ] 验证：格式化输出与 Python 版本一致

**参考源码**：`construct/construct/core.py` → `Hex` (line ~3459), `HexDump` (line ~3481)

### 4.5 If / IfThenElse / Switch

- [ ] 实现 `If`：条件构造器
  - 条件为 true 时解析/构建子构造器，否则返回 None
  - 支持表达式条件
- [ ] 实现 `IfThenElse`：二选一条件
  - 条件为 true 使用 `then_constr`，否则使用 `else_constr`
- [ ] 实现 `Switch`：多分支选择
  - 根据 key 字段值选择对应子构造器
  - 支持 `default` 默认分支
  - 支持 `include_key` 选项
- [ ] 验证：各种条件分支正确，默认分支正确

**参考源码**：`construct/construct/core.py` → `If` (line ~3560), `IfThenElse` (line ~3625), `Switch` (line ~3695)

### 4.6 Check / StopIf

- [ ] 实现 `Check`：断言条件为 true
  - parse/build 时检查条件，失败抛出 `CheckError`
- [ ] 实现 `StopIf`：在 Struct/Sequence 中提前终止
  - 仅在 parse 时生效，条件为 true 时停止后续字段解析
- [ ] 验证：校验逻辑正确

**参考源码**：`construct/construct/core.py` → `Check` (line ~3533), `StopIf` (line ~3667)

### 4.7 Computed / Rebuild / Default / Index

- [ ] 实现 `Computed`：计算字段（不读写流）
  - 接受闭包或表达式，返回计算值
- [ ] 实现 `Rebuild`：构建时从上下文重建值
- [ ] 实现 `Default`：构建时如果缺失则使用默认值
- [ ] 实现 `Index`：返回当前重复索引
- [ ] 验证：计算字段正确注入上下文

**参考源码**：`construct/construct/core.py` → `Computed` (line ~2848), `Rebuild` (line ~2901), `Default` (line ~2941), `Index` (line ~2973)

### 4.8 Padded / Aligned / FixedSized

- [ ] 实现 `Padded`：固定大小，多余部分用填充字节
- [ ] 实现 `Aligned`：对齐到指定字节边界
- [ ] 实现 `FixedSized`：固定大小包装器
- [ ] 验证：填充/对齐计算正确

**参考源码**：`construct/construct/core.py` → `Padded` (line ~2995), `Aligned` (line ~3071), `FixedSized`

### 4.9 NamedTuple / TimestampAdapter

- [ ] 实现 `NamedTuple`：解析为具名元组
- [ ] 实现 `TimestampAdapter`：时间戳适配
- [ ] 验证：与 Python 版本行为一致

### 4.10 单元测试

- [ ] 为每个适配器和控制流构造器编写测试
- [ ] 重点测试：条件分支、映射边界、校验失败场景
- [ ] 验证：`cargo test` 全部通过

## 阶段出口标准 (Exit Criteria)

1. **编译通过**：`cargo build` / `cargo clippy` 无问题
2. **测试通过**：`cargo test` 全部 PASS
3. **功能完整**：
   - Adapter/SymmetricAdapter/Validator 基础架构可用
   - Enum/FlagsEnum/Mapping 双向映射正确
   - If/IfThenElse/Switch 条件逻辑正确
   - Check/StopIf 流程控制正确
   - Computed/Rebuild/Default 上下文字段正确
   - Padded/Aligned 大小计算正确
4. **parse/build 对称性**：所有构造器满足对称性
5. **错误处理**：所有非法输入返回正确错误类型

## 预估工期

~2 周

## 风险与注意事项

- `Adapter` 的 decode/encode 签名需考虑 `Value` 类型的灵活性
- `Switch` 的 key 获取机制依赖表达式系统（Phase 5），本阶段可用简单闭包占位
- `Enum` 的映射表设计需考虑 Rust 中 `HashMap` 与 `BTreeMap` 的选择
- `Computed` 的闭包需要 `Fn` trait 约束，注意生命周期
