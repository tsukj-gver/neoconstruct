## 风险与注意事项

- 过早优化可能浪费时间，需基于基准测试数据驱动
- 零拷贝优化可能增加 API 复杂度（生命周期参数）
- trait 对象 → 泛型的重构可能影响 API 兼容性
- 编译优化是高级功能，可酌情延后
