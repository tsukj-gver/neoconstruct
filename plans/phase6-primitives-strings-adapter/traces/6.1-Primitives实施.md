## 3. 偏离设计文档

### 3.1 [设计质疑] sizeof 错误类型（小问题）

**设计 §1.4.1 D-5 / §1.4.2**：VarInt / ZigZag sizeof "返回 Err(SizeofError)"。

**实际实现**：返回 `ConstructError::Generic`。

**原因**：`src/error.rs` 无 `ConstructError::Sizeof` 变体。项目惯例（`GreedyRangeNode` / `PrefixedArrayNode`）变长字段 sizeof 用 `Generic`。Python 端 SizeofError 是 ConstructError 子类，`except ConstructError` 仍可捕获。

**建议**：若需精确 `except SizeofError`，后续可给 error.rs 加 `Sizeof` 变体并在 select_exception_class 加映射。当前遵循项目惯例。

### 3.2 [偏离] Python 3.11+ int.to_bytes/from_bytes signed 参数

**设计 §1.5.3-1.5.4**：`int.from_bytes(bytes, byteorder, signed)` / `int.to_bytes(length, byteorder, signed)` 位置传 3 参数。

**实际实现**：`signed` 通过 kwargs 传递（`call_method("from_bytes", (bytes, byteorder), Some(&kwargs))`）。

**原因**：Python 3.11+ 的 `int.from_bytes` / `int.to_bytes` 中 `signed` 是 keyword-only 参数（`*, signed=False`），位置传 3 个参数触发 TypeError。这是 Python API 事实，非设计意图偏离。

### 3.3 [偏离] format_field 测试更新

**原测试** `format_from_chars_invalid_returns_none` 断言 `from_chars('>', 'f') == None`。

**修正**：Phase 6.1 后 'f' 是有效的（Float32Big）。改用其他无效字符（'F'/'E'/'D'）验证 None 分支。这是现有测试的必要更新，非设计偏离。
