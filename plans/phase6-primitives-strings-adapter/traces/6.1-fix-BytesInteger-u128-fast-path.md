### 任务范围

- 扩展 BytesInteger fast-path 从 `length ≤ 8`（u64/i64）到 `length ≤ 16`（u128/i128 via pyo3 `IntoPy`）
- `length > 16` 保持 Python `int.from_bytes` / `int.to_bytes` slow-path 不变
- 修复 6.6 VET 发现的 BytesInteger(16) 单点 2.82x（低于 ≥4x 门禁）

### 设计依据

`docs/design/queries/设计质疑-BytesInteger-num-bigint.md` §3.1：
- pyo3 0.22 原生支持 `u128/i128::into_py`（内部封装 `_PyLong_FromByteArray`-类 C API，
  construct-rs 视角零 unsafe，与 `u64::into_py` 调 `PyLong_FromLongLong` 同性质）
- phase3 实测 `i128::into_py(42)` = 21.63ns，`i128::into_py(-1)` = 57.18ns
- §0 原则对照（§5.4）：u128/i128 是 Rust 原生整数，pyo3 直接 ↔ PyLong，不违反 §0 #2

### 实现要点

1. **常量分档**：移除 `FAST_PATH_MAX_LEN=8`，新增 `U64_PATH_MAX=8` / `U128_PATH_MAX=16`
2. **parse 三档**：≤8 走 u64/i64 fast-path（不变）；9-16 走 u128/i128 fast-path（新增，
   逻辑与 u64 路径同构，仅位宽 8→16 字节）；>16 走 Python slow-path（不变）
3. **build 三档**：同 parse 分档；9-16 用 `extract::<i128>` / `extract::<u128>` + 新增
   `check_range_u128` 范围检查
4. **`check_range_u128` 边界处理**：bits ∈ [72, 128]。**关键陷阱**：`bits=128`（length=16）
   时不能用 `1i128 << 127`（wrap 成 i128::MIN，`half-1` 再溢出 panic），也不能用
   `checked_shl`（它只检查 shift amount 不检查值溢出）。正确做法：`if bits >= 128`
   显式判定全范围有效，bits ∈ [72,120] 时 `1i128 << (bits-1)` 安全（half ≤ 2^119）。
5. **错误信息去重**：新增 `out_of_range_int_error` helper（替代 check_range / check_range_u128
   中重复的 repr 格式化）

### 性能验证（B5 = BytesInteger(16)）

环境：`.venv` (CPython 3.14, maturin develop --release, PYO3_USE_ABI3_FORWARD_COMPATIBILITY=1)
对照：临时 venv (Python 3.13, construct==2.10.70)

| 场景 | 修改前（6.6） | 修改后 | 加速比提升 | 门禁 |
|------|-------------|--------|----------|------|
| B5-parse | 2.82x | **9.01x** (rs=243ns, py=2191ns) | 3.2x | ≥8x ✅（设计质疑 §4.2 修正门禁 BYTESINT-mid） |
| B5-build | 2.82x | **12.02x** (rs=178ns, py=2137ns) | 4.3x | ≥10x ✅（原硬门禁） |

设计质疑 §4.1 预测 9-16 字节 ~8-12x：实测 9.01x(parse)/12.02x(build) **完全符合预测区间**。

### 测试覆盖（新增 13 个 + 重命名 3 个）

- **parse u128 fast-path**（8 个）：16 字节 zero/unsigned BE/unsigned LE/signed -1/unsigned max(u128)；
  9 字节 signed min(-2^71)/unsigned LE
- **build u128 fast-path**（8 个）：16 字节 2^64/max unsigned/signed -1/little endian/overflow(2^128)；
  9 字节 signed min(-2^71)/unsigned overflow(2^72)/signed overflow(2^71)
- **slow-path 边界**（2 个）：17 字节 parse zero / build 2^128（验证 >16 字节仍走 slow-path）
- **round-trip**（3 个新增）：16 字节 large value(2^100+12345) / signed negative(-(2^70+999)) /
  little endian
