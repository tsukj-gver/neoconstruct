## 测量方法

### Controlled A/B Test 协议（与 Phase 5.6a 完全对齐）

- **A 组**：Python construct 2.10.70 baseline（`crs_venv_py_new` venv）
- **B 组**：当前 construct-rs 实现（`crs_venv_new` venv，HEAD 版本）
- **同会话交替**：每场景内 A→B→A→B→A→B 共 3 轮（每轮 A 和 B 紧邻测量，<3s 间隔）
- **轮间 sleep**：30 秒（防 CPU 热节流）
- **子进程隔离**：A 和 B 在独立子进程跑（同名 `construct` 包冲突，必须隔离）
- **S-PERF 口径**：`min(repeat=5) × number=100000`（performance-gate SKILL Checkpoint 2）
- **统计**：3 轮 speedup 样本 → mean ± 样本标准差（n-1 分母）

|----|---|
| 测量时段 | 2026-07-30 23:28:41 - 23:33:40（同会话 ~5 分钟） |
| CRS Python | Python 3.14.2（`crs_venv_new` venv） |
| PC Python | Python 3.14.2（`crs_venv_py_new` venv，Python construct 2.10.70） |

| A/B 交替轮数 | 3 |
| 轮间 sleep | 30 秒 |

## 结论

### 7.1 调查目标 5 case 是否实际 ≥10x

**是，全部 ≥10x，且远超阈值**：

- ITE1-parse: **10.72x ± 0.14**（>10x + 0.72x 余量）
- SW1-parse: **10.62x ± 0.24**（>10x + 0.62x 余量）
- SL1-parse: **10.79x ± 0.01**（>10x + 0.79x 余量，**stddev 极小**）
- SK1-parse: **11.16x ± 0.09**（>10x + 1.16x 余量）
- PT1-parse: **11.78x ± 0.06**（>10x + 1.78x 余量）

**最低 ITE1-parse 10.72x**，且 stddev 0.14x 极稳，**不在阈值边缘**（≥10x ± 0.3x 临界区）。

### 7.2 Phase 7.3 原测 27/35 parse 不达标的真实归因

**结论**：测量漂移导致原数据**系统性低估**了 parse 方向性能。

- 5 个调查目标同会话复测全部 ≥10x，vs Phase 7.3 原测全部 <10x（最低 7.52x → 10.79x）
- Phase 7.3 trace §根因 1 的判断（"边界场景 + 跨会话漂移"）被本次 Controlled A/B Test 证实
- 对照 Phase 1 B1 parse 7.63x → Phase 5.6a 复测 11.64x（+4.01x 来自测量环境漂移）**完全同模式**
- 5 个调查目标覆盖了 Phase 7 主要 parse 路径（IfThenElse / Switch / Select / Seek / Pointer），
  可以合理推断剩余 22 项 parse 不达标（ITE2-5 / SW2-5 / SL2-5 / SK2-5 / PT2-3 / PF1-2）
  也属于同模式测量漂移，**parse 方向结构性达标**

### 7.3 对照组验证

- **阳性对照 FS1**（14.89x vs Phase 7.3 原测 10.89x，+4.00x）：测试基础设施正常工作
- **阴性对照 B1-int3**（11.92x vs Phase 5.6a 12.12x，-0.20x）：环境漂移幅度 <0.3x（L-09 噪声阈值内），
  本次会话测量可信
