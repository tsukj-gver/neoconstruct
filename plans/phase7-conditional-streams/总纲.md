# Phase 7：Conditional + Streams

## 目标

实现协议常用层的分支与流操作构造器：

1. **Conditional**（5 个未实现）：If / IfThenElse / Switch / Select / FocusedSeq
2. **Streams 关键**（3 个）：Pointer / Prefixed / Seek

## 范围

### Conditional 5 个

| 构造器 | 备注 |
|--------|------|
| If | 条件执行（cond ? subcon : 默认） |
| IfThenElse | 双分支 |
| Switch | 多路分支（keyfunc → subcon 映射） |
| Select | 首个匹配的子构造器 |
| FocusedSeq | 聚焦序列（Phase 4 StopIf 已部分实现聚焦语义） |

### Streams 3 个

| 构造器 | 备注 |
|--------|------|
| Pointer | 绝对偏移读写 |
| Prefixed | 前缀长度 + 子流 |
| Seek | 流定位 |

## 依赖

- Phase 6（Adapter / Subconstruct 是 Conditional/Streams 的依赖）
- Phase 2 表达式系统（Switch 的 keyfunc 可能用表达式）
