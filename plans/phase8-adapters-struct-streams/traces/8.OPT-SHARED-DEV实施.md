## 2. 三件套实施细节

### 2.1 O1-A：StructNode.parse 用 PyObject_GenericGetDict 替代 getattr(__dict__)

**改动文件**：
- `construct-rs/src/instance.rs`：新增 `pub fn dict_via_generic_getdict<'py>(py, instance) -> PyResult<Bound<'py, PyDict>>`
- `construct-rs/src/nodes/struct_node.rs`：parse 路径 dict 获取改为 `match dict_via_generic_getdict(py, &instance) { Ok(d) => d, Err(_) => /* fallback getattr */ }`

**SAFETY 注释示例**（instance.rs L211-217）：
```rust
// SAFETY:
// - instance.as_ptr() 是有效的 PyObject 指针（pyo3 Bound 守护）
// - PyObject_GenericGetDict 是 CPython 公开 Stable ABI（自 3.10 起），签名稳定：
//   `PyObject *PyObject_GenericGetDict(PyObject *obj, void *context)`
// - GIL 持有（由 py: Python<'py> 参数保证）
// - context 参数 NULL（CPython 文档：__dict__ getset descriptor 调用时传 NULL）
// 返回值是 owned reference（new reference），由调用方负责 decref。
let dict_ptr = unsafe { ffi::PyObject_GenericGetDict(instance.as_ptr(), std::ptr::null_mut()) };
```

**退化路径**（设计 §1.1.5）：GenericGetDict 返回 NULL / 非 PyDict / slots class 时
fallback 到 R4 原 getattr 路径，保留 slots class 错误信息。

**ABI 依赖**：`PyObject_GenericGetDict` 是 CPython Stable ABI since 3.10
（NB2-1 REV 提示已确认：函数 Added in 3.3，Stable ABI since 3.10）。pyo3 0.22
在 `pyo3-ffi-0.22.6/src/object.rs` L373 暴露（NB2-3：实际 cfg 守护
`#[cfg(not(all(Py_LIMITED_API, not(Py_3_10))))]`，Python ≥ 3.10 下 abi3/非 abi3 均可用）。

### 2.2 O1-B：PyDict_SetItem_KnownHash 替代 PyDict_SetItem

**改动文件**：
- `construct-rs/src/instance.rs`：新增 `pub fn set_item_knownhash(py, dict, key, value, hash) -> PyResult<()>`
- `construct-rs/src/nodes/struct_node.rs`：
  - `FieldName` 新增 `cached_hash: ffi::Py_hash_t` 字段
  - `FieldName::new` 编译期 `PyObject_Hash` + 缓存（NB-4：返回 -1 panic）
  - 新增 `FieldName::cached_hash()` accessor
  - 无表达式路径：`dict_bound.set_item(...)` → `set_item_knownhash(..., field.name.cached_hash())`
- `construct-rs/src/context.rs`：新增 `pub fn set_field_at_knownhash(idx, name, value, hash, py) -> PyResult<()>`
  - 供 StructNode.parse has_expressions 路径使用（其他节点保持原 `set_field_at`）

**NB-4 修复**（设计 §1.2.2 + §7 #8）：`FieldName::new` 中 `PyObject_Hash` 返回 -1
时 panic，注释明确"构造期错误，比运行期退化更明确"。interned PyString 理论不会失败，
此 panic 仅 OOM 等极端场景触发。

**SAFETY 注释示例**（instance.rs L283-288）：
```rust
// SAFETY:
// - dict / key / value 由 pyo3 Bound 守护，均为有效 PyObject 指针
// - dict 是 Bound<PyDict>，保证是 PyDictObject（_PyDict_SetItem_KnownHash 要求）
// - GIL 持有保证单线程访问
// - hash 由 FieldName 编译期一次性 PyObject_Hash 计算并缓存（interned PyString
//   hash 在其生命周期内不变，CPython 强约束）
let result = unsafe {
    ffi::_PyDict_SetItem_KnownHash(dict.as_ptr(), key.as_ptr(), value.as_ptr(), hash)
};
```

**ABI 依赖**：`_PyDict_SetItem_KnownHash` 是 CPython Internal Function（非 stable ABI），
pyo3 0.22 cpython 子模块暴露（NB2-2：cpython/dictobject.rs L29，经 cpython/mod.rs
二次守护 `#[cfg(not(PyPy))]`）。项目锁定 CPython AMD64 + 非 abi3，PyPy 不会触发。

### 2.3 O2-A：_parse_raw 入口用 PyBytesObject.ob_sval 直读

**改动文件**：
- `construct-rs/src/schema.rs`：`_parse_raw` 签名 + 实现修改
  - 返回类型 `PyResult<Bound<'py, PyAny>>` → `PyResult<Py<PyAny>>`（省 pyo3 Bound 包装 ~1-2ns）
  - `data.as_bytes()` → 直接访问 `PyBytesObject.ob_sval` 字段（绕过 `PyBytes_AsStringAndSize`）
- `construct-rs/src/compile.rs`（仅测试代码）：17 处 `_parse_raw(...).expect(...)`
  追加 `.into_bound(py)` 以适配新返回类型（业务代码无影响）

**SAFETY 注释示例**（schema.rs L162-175）：
```rust
// SAFETY:
// - data 是 &Bound<'py, PyBytes>，pyo3 参数类型签名在入口处 type check
//   （PyBytes_CheckExact 通过才进入此函数）。直接将 PyObject* cast 为
//   PyBytesObject* 是 CPython 内部约定。
// - ob_sval 字段声明为 `[c_char; 1]` 是占位（CPython 不变量：实际长度为
//   ob_base.ob_size + 1，含终止 NUL；`from_raw_parts` 的 len 取 ob_size，
//   不含 NUL）。
// - 返回的 &[u8] 生命周期受 `data` 借用约束（Rust borrow checker 保证）。
// - GIL 持有（由 `py: Python<'py>` 参数保证）。
let bytes: &[u8] = unsafe {
    use pyo3::ffi::PyBytesObject;
    let bytes_ptr = data.as_ptr() as *const PyBytesObject;
    let bytes_obj = &*bytes_ptr;
    let len = bytes_obj.ob_base.ob_size as usize;
    std::slice::from_raw_parts(bytes_obj.ob_sval.as_ptr() as *const u8, len)
};
```

**ABI 依赖**：`PyBytesObject.ob_sval` + `ob_base.ob_size` 是 CPython Internal Struct，
pyo3 0.22 cpython 子模块暴露（NB-1：实际 cfg 守护 `#[cfg(not(any(PyPy, GraalPy, Py_LIMITED_API)))]`）。
