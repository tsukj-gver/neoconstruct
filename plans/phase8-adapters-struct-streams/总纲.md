### 关键设计框架（ARCH §0.2）

"FFI crossing（调用用户 Python 代码）≠ C API 操作（直接操作内置类型）"——Enum/FlagsEnum/Mapping/OneOf/NoneOf/NamedTuple 可走 Rust Node（持有编译期物化的 Py<PyDict>/Py<PyFrozenSet>/Py<PyType>，运行时 C API 查询，全程 1 次 FFI）。
