### 关键路径核查

#### 1. push_path_index INSERT-after-root 正确性（最关键）

设计文档 §2.2.1 声明 `push_path_index` 用 INSERT-after-root 策略，把 `[i]` 插入到 `"root"` 之后、已有 suffix 之前。VET 通过代码阅读 + 9 个单元测试 + 传递性论证确认正确性。

**实现核查**（`error.rs` L425-445）：
```rust
pub fn push_path_index(&mut self, i: usize) {
    if self.path().is_none() { return; }  // 编译期错误 noop
    let new_path = match self.path() {
        Some(p) if p.is_empty() || p == "root" => format!("root[{}]", i),
        Some(p) => {
            if let Some(suffix) = p.strip_prefix("root") {
                format!("root[{}]{}", i, suffix)  // INSERT after root
            } else {
                format!("{}[{}]", p, i)  // 非标准根，退化为追加
            }
        }
        None => format!("root[{}]", i),
    };
    self.set_path(new_path);
}
```

✅ 与设计 §2.2.1 完全一致。与 `push_path_segment` 平行设计，共享 INSERT-after-root 逻辑。

**5 种嵌套组合覆盖**：

#### 3. Vec PyList 引用计数安全

**模式**（以 ArrayNode.parse 为例）：
```rust
let mut elems: Vec<Py<PyAny>> = Vec::with_capacity(count);
for i in 0..count {
    let elem = match self.inner.parse(...) { Ok(v) => v, Err(e) => { return Err(e); } };
    if !self.discard { elems.push(elem); } else { drop(elem); }
}
let list = PyList::new_bound(py, elems);
```

**引用计数核查**：
- 成功路径：`elems.push(elem)` 移动 ownership 到 Vec；Vec 最终移动到 `PyList::new_bound`，pyo3 正确处理引用转移 ✅
- 错误路径：`return Err(e)` 丢弃 `elems`，每个 `Py<PyAny>` 的 Drop 调用 `Py_DECREF` ✅
- discard 路径：`drop(elem)` 显式释放（虽然冗余，因为 elem 会在迭代结束时 drop，但 explicit 清晰） ✅
- RepeatUntil Expr：`elems.push(elem.clone_ref(py))` 正确——谓词求值需用原始 `elem`（通过 `_current_elem_ptr`），Vec 存副本 ✅
- RepeatUntil PyCallable parse：保持 `list.append(elem.clone_ref(py))`——谓词签名 `(obj, list, ctx)` 需实时 PyList ✅

**discard 语义等价性**：
- 旧（PyList）：discard 时不 `list.append(elem)`，elem 在迭代结束时 drop
- 新（Vec）：discard 时不 `elems.push(elem)`，elem 显式 drop
- 行为完全等价 ✅
