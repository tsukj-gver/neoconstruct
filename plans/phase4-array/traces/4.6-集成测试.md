**修复前行为**（以 ArrayNode.parse 为例）：
```
inner.parse(path=root[i]) 抛错 → error.path = "root[i]"
path.pop() → path = root
e.push_path_segment("[i]") → 把 "[i]" 插入 "root" 之后：
  p="root[i]", strip_prefix("root")="[i]"
  format!("root.{}{}", "[i]", "[i]") = "root.[i][i]"  ❌ 双重标记
```

**修复后行为**：
```
inner.parse(path=root[i]) 抛错 → error.path = "root[i]"
path.pop() → path = root
不调用 push_path_segment → error.path 保持 "root[i]"  ✅
```

**嵌套场景验证**（修复后）：
- 嵌套 Array：外层 [1] → 内层 [1] → inner 失败 → `path = "root[1][1]"` ✅
- Array(Struct)：[0] → Struct 不 push 字段 → inner 失败 → `path = "root[0]"` ✅

**修复原理核查**：

修复前（以 ArrayNode.parse 为例）：
```
inner.parse(path=root[i]) 抛错 → error.path = "root[i]"
path.pop() → path = root
e.push_path_segment("[i]") → strip_prefix("root")="[i]"
  format!("root.{}{}", "[i]", "[i]") = "root.[i][i]"  ❌ 双重标记
```

修复后：
```
inner.parse(path=root[i]) 抛错 → error.path = "root[i]"  ✅
```

嵌套场景：外层 [1] → 内层 [1] → inner 失败 → `path = "root[1][1]"` ✅
