# Phase 4：Array 支持

## 目标

实现数组/重复构造器，支持在二进制协议中解析和构建重复元素。

## 分析报告

`plans/phase4-array/分析报告-Array功能集.md`

## 功能范围

| 构造器 | 功能 | 优先级 |
|--------|------|--------|
| Array(count, subcon) | 固定次数数组 | P0 |
| GreedyRange(subcon) | 读到流结束 | P1 |
| PrefixedArray(countfield, subcon) | 前缀长度数组 | P2 |
| RepeatUntil(predicate, subcon) | 谓词终止 | P3 |
| Index | 数组内取当前下标 | P4 |
| StopIf | GreedyRange 早停 | P5 |

## PM 决策

1. RepeatUntil Expr 谓词路径：Phase 4 内完成，不延后
2. ListContainer：直接返回原生 list
3. PrefixedArray：独立 Node，不依赖 FocusedSeq/Rebuild
4. inner 表达式限制（如 Array(N, Bytes(this.m))）：编译期失败，与 Bitwise(Bytes(this.m)) 一致，后续阶段扩展

| 标准 | 要求 |
|------|------|
| S-FUNC | 全部 Rust + Python 测试通过；Array 相关构造器行为与 Python construct 一致 |
| S-QUAL | clippy 零 warning + fmt 通过 |
| S-PERF | Array parse/build ≥10x vs Python construct（具体场景待 ARCH 设计确认） |
