# Phase 3：BitStream 支持

## 目标

实现 Bitwise 相关的位级二进制操作，支持在 bit 级别解析和构建数据。

## 分析报告

`plans/phase3-bitstream/分析报告-Bitwise功能集.md` — Python construct 2.10.70 的 Bitwise 完整功能集调查。

## 设计文档

`docs/design/模块设计-BitStream.md`（v2，REV 通过）

## 功能范围

需要实现的构造器：

| 构造器 | 功能 |
|--------|------|
| Bitwise(subcon) | 核心包装器，字节流 ↔ bit 流 |
| BitStruct | Bitwise(Struct(...)) 语法糖 |
| BitsInteger(length, signed, swapped) | 读 N 个 bit 转整数 |
| Bit / Nibble / Octet | BitsInteger(1) / (4) / (8) |
| Bytewise(subcon) | Bitwise 内部逆操作 |
| BitsSwapped(subcon) | 字节内 bit 序翻转 |
| ByteSwapped(subcon) | 字节序翻转 |
| Padding | 字节级 + 位级填充 |

## PM 决策

1. BitsInteger 表达式 length：本阶段仅常量，表达式留后续
2. 字节级 PaddingNode：纳入
3. Bytewise 未对齐慢路径：完整实现
