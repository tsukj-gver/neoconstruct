- 当 data 为 None 且所有 subcon 的 flagbuildnone=true 时，自动创建等长 None 列表

2. **RepeatUntil build 无匹配时的错误类型**：Python 抛出 `RepeatError`，Rust 返回 `ConstructError::Array`。语义等价（都表示"重复构建失败"），但错误变体不同。这是可接受的简化。
3. **GreedyRange 不区分 ExplicitError**：Python 中 `ExplicitError` 直接传播（不 seek back），Rust 中所有错误都 seek back。目前没有 `ExplicitError` 对应构造器，实际不影响。

#### sizeof 一致性

- Array: Python `count * subcon._sizeof()` ↔ Rust `count.saturating_mul(sub_size)` ✅
- GreedyRange: Python raises `SizeofError` ↔ Rust returns `ConstructError::Sizeof` ✅
- RepeatUntil: Python raises `SizeofError` ↔ Rust returns `ConstructError::Sizeof` ✅

**子任务 3.3 结论**：✅ **通过**（已知差异均因 Phase 5 表达式系统未就绪或可接受的错误类型简化）
