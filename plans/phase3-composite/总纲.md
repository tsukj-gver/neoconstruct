# Phase 3: 复合与重复构造器

## 阶段目标

实现复合构造器（Struct, Sequence, Union, Select 等）和重复构造器（Array, GreedyRange, RepeatUntil）。这些构造器将原子构造器组合为复杂的数据结构。

## 前置依赖

- Phase 1 完成
- Phase 2 完成（原子构造器可用）

## 子任务清单

### 3.1 Struct 构造器

- [ ] 实现 `Struct`：命名字段的有序集合
  - 内部存储：`Vec<(String, Box<dyn Construct>)>`
  - parse: 按顺序解析所有子字段，返回 `Value::Container`
  - build: 按顺序构建所有子字段，从 `Value::Container` 中取值
  - sizeof: 累加所有子字段大小
  - 上下文嵌套：每个字段解析结果插入 Context，后续字段可引用
- [ ] 实现运算符方法（`add` 对应 Python 的 `+` 拼接）
- [ ] 验证：多字段 Struct parse/build 正确，字段间上下文引用正确

**参考源码**：`construct/construct/core.py` → `Struct` (line ~2162)

### 3.2 Sequence 构造器

- [ ] 实现 `Sequence`：有序无名序列
  - 内部存储：`Vec<Box<dyn Construct>>`
  - parse: 返回 `Value::List`
  - build: 从 `Value::List` 按序构建
  - 上下文：每个元素的索引可通过 `Index` 构造器获取
- [ ] 实现运算符方法（`shl` / `>>` 对应序列拼接）
- [ ] 验证：序列 parse/build 对称性

**参考源码**：`construct/construct/core.py` → `Sequence` (line ~2329)

### 3.3 Array / GreedyRange / RepeatUntil

- [ ] 实现 `Array`：固定长度重复
  - 支持 `count` 参数（整数或表达式）
  - parse: 重复解析 N 次，返回 `Value::List`
  - build: 从 `Value::List` 构建所有元素
  - 验证元素数量匹配
- [ ] 实现 `GreedyRange`：重复解析到流末尾
- [ ] 实现 `RepeatUntil`：重复直到条件满足
  - 条件函数接收 `(element, context)` 返回 bool
- [ ] 验证：三种重复模式行为正确

**参考源码**：`construct/construct/core.py` → `Array` (line ~2493), `GreedyRange` (line ~2587), `RepeatUntil` (line ~2635)

### 3.4 Union 构造器

- [ ] 实现 `Union`：多构造器解析同一数据，返回合并结果
  - 支持 `buildfrom` 指定构建时使用的子构造器
  - parse: 每个子构造器从同一位置开始解析，合并所有结果到 Container
  - build: 仅使用 buildfrom 指定的构造器构建
- [ ] 验证：多路径解析正确，构建使用正确子构造器

**参考源码**：`construct/construct/core.py` → `Union` (line ~3829)

### 3.5 Select 构造器

- [ ] 实现 `Select`：依次尝试多个构造器，使用第一个成功的
  - parse: 按顺序尝试，返回第一个成功结果
  - build: 使用第一个子构造器构建
  - 包含 `incl_absorb` 选项
- [ ] 验证：正确选择匹配的构造器，全部失败时返回错误

**参考源码**：`construct/construct/core.py` → `Select` (line ~3953)

### 3.6 FocusedSeq 构造器

- [ ] 实现 `FocusedSeq`：解析序列但仅返回指定索引的元素
  - `parse`: 解析所有子构造器，返回指定索引的值
  - `build`: 从单个值构建整个序列
- [ ] 验证：正确提取指定索引元素

**参考源码**：`construct/construct/core.py` → `FocusedSeq` (line ~2401)

### 3.7 单元测试

- [ ] 测试 Struct 多字段解析与构建
- [ ] 测试 Sequence 有序解析
- [ ] 测试 Array/GreedyRange/RepeatUntil 各种场景
- [ ] 测试 Union 多路径解析
- [ ] 测试 Select 容错选择
- [ ] 测试上下文传递与嵌套
- [ ] 验证：`cargo test` 全部通过

## 阶段出口标准 (Exit Criteria)

1. **编译通过**：`cargo build` / `cargo clippy` 无问题
2. **测试通过**：`cargo test` 全部 PASS
3. **功能完整**：
   - `Struct` 可组合任意原子构造器为命名结构
   - `Sequence` 可组合为有序序列
   - 三种重复模式（Array/GreedyRange/RepeatUntil）正常工作
   - `Union` 和 `Select` 正确处理多构造器场景
   - 上下文在字段间正确传递
4. **parse/build 对称性**：所有构造器满足 `parse(build(x)) == x`

## 预估工期

~2 周

## 风险与注意事项

- `Struct` 是最关键的复合构造器，其上下文传递机制需要与 Python 版本完全一致
- `RepeatUntil` 的条件函数需要设计好 Rust 中的闭包接口
- `Union` 的"同位置多次解析"对流 seek 操作有要求
- 复合构造器的错误追踪（path）需要正确拼接子路径
